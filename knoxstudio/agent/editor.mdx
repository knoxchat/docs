# Editor agent

Dock **Editor**. Empty: “Ask the SI to edit the timeline — video, audio, and images. Cut, trim, split, move, retime, mix, and place media. It can watch and listen to decide what to do.”

Tracks it knows: Video, Audio, Camera, Annotation, Adjustment, Caption.

Destructive batches in **Confirm** show **Confirm edits** with **Apply** / **Discard**.

## What you can ask

Examples the tools support:

- “Remove the silences.” (`analyze_timeline` silence + cuts)
- “Cut on every scene change.”
- “Cut to where she says…” (`transcribe_clip`)
- “Caption this clip.”
- “Slow this down.” (uses the current selection)

| Group | Examples |
