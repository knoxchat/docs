# What's new in 1.7

User-facing highlights. The full engineering changelog is [CHANGELOG.md](https://github.com/knoxchat/knoxstudio/blob/main/CHANGELOG.md) in the repo.

## 1.7.3

- Forced GitHub Release updates (no Skip Version)
- Screenplay Read / Edit / Outline with One Dark Pro markdown, Fountain + Knox + literary dialects
- Export HTML, Final Draft (FDX), Knox Markdown; print preview ⌘P
- Character, relationship, and comment panels

## 1.7.2

- Voice Library and collections in Character Roles
- Voice Changer uses the selected account voice
- Default public TTS voice **Jarnathan**

## 1.7.1

- Explorer, Inspector, Timeline, Canvas, Screenplay as Voice Director HUD companions
- HUD follows light and dark theme

## 1.7.0

- Circular **Voice Director** orb
- Left sidebar renamed **Explorer**
- Positioned as a general SI studio (not video-only)
- **Sign in with KnoxStudio** is the only connect path
- One `knox/knox-studio` model; server picks the specialist

## 1.6.x (still how the studio works)

- BM25 + ripgrep library search; `@` resolves files not on the timeline
- SI Agent Configuration is a single pane
- Recording countdown 1–60 s or off
