# Glossary

| Term | Meaning |
|---|---|
| **SI Agent** | The right-panel studio agent (and Voice Director when a call is up) |
| **Manager** | Default specialist: generate and route |
| **Writer** | Documents and screenplays under `~/.knoxmedia` |
| **Editor** | Timeline operations in plain language |
| **Director** | Shot-list pipeline from a prompt or screenplay |
| **Storyboard** | Style → script → cast → frames → video pipeline |
| **Voice Director** | Realtime speech-to-speech of the same agent |
| **Confirm / Auto** | Whether generations and destructive edits wait for Approve |
| **Explorer** | Left tree of `~/.knoxmedia` |
| **Canvas** | Preview compositor (center tab) |
| **Screenplay** | Writing surface (center tab) |
| **`.knoxstudio`** | Project package |
| **`~/.knoxmedia`** | Generated media, docs, roles, chat DB, config |
| **Knox-Studio** | Model id `knox/knox-studio` — one model, server-routed specialists |
| **Compound clip** | Nested sequence |
| **Ripple / Insert / Overwrite** | Timeline edit modes (plus Normal) |
| **Character Role** | Named cast record with refs and voice |
| **Video sequence** | Continuity-aware multi-shot run |
| **Take / Variation** | Alternate SI generations of one prompt |
| **anydoc** | Office/PDF → Markdown converter |
| **Knox dialect** | `[NAME]` character cue in screenplays |
| **Recording Setup** | Preflight dialog before a take (permissions, meters, **This take will include**, Start Recording) |
| **Follow** | Stick a layer to another clip’s position |
| **Auto-key** | Inspector checkbox: write a key at the playhead on every change |
| **Crop** | Normalized source window on Actions / canvas inner handles |
| **Compound clip / nest** | Nested sequence inside the `.knoxstudio` package |
| **Image Gen** | Timeline toolbar: merge selected stills into one generated image |
