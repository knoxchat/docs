# Keyboard shortcuts

Press <kbd>?</kbd> in the app for the overlay. Same list as **Help → Keyboard Shortcuts** / **View → Keyboard Shortcuts**. KnoxStudio is macOS-only.

Focus matters: NLE chords apply on the timeline/canvas; Screenplay and Explorer have their own groups.

## Playback

| Keys | Action |
|---|---|
| Space | Play / Pause |
| J K L | Shuttle reverse / pause / play (tap 2× / 4× / 8×) |
| Home / End | Go to start / end |
| ← → | Step frame (yields to annotation nudge) |
| ⌘← ⌘→ | Prev / next marker |
| ⌥→ | Next clip start |
| ⇧L | Toggle loop |

Transport ±1 s has no overlay key.

## Editing

| Keys | Action |
|---|---|
| T / W / E | Split / trim front / trim end at playhead |
| B Y A V | Blade / Slip / Magnetic / Select |
| Z | Zoom to region |
| I O | In / out |
| M | Marker |
| ⌘T | Add transition |
| ⌘⇧F | Freeze frame |
| ⌘] ⌘[ | Rotate 90° |
| ⌥ drag / ⌘ drag / ⌥ drop / ⇧ drag | Copy / overwrite / replace / constrain |
| ⌥ drag | Move transform origin |

## Selection

| Keys | Action |
|---|---|
| ⌘A | Select all clips |
| ⌘C ⌘X | Copy / cut (keyframes if diamonds selected) |
| ⌘V | Paste at playhead |
| ⌘D | Duplicate |
| Delete / Backspace | Delete |
| ⇧Delete / ⇧Backspace | Ripple delete |
| ⌘Delete / ⌘Backspace | Ripple delete in/out |
| ⌘G / ⌘U | Group / ungroup |
| ⌘⌥G | New compound clip |
| ⌘↑ | Parent sequence |
| ⌘⌥L | Lock / unlock |

## Annotations

1–9, 0, ⇧0 as on the <Link to="/knoxstudio/canvas/annotations">Annotations</Link> page. Arrows nudge (⇧ = 5×).
