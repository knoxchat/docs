# Storyboard

Dock **Storyboard**. Separate from Director. Full production: screenplay, portraits, keyframes, and timeline clips.

Intro: “Open a project, pick a visual style, then describe your story below to generate a full production — screenplay, portraits, keyframes, and timeline clips.”

## Steps

**Style** → **Script** → **Cast** → **Scenes** → **Frames** → **Video**

1. **Open or create a project** — **Project name**, **Recent projects**, **Open / Create**. Leave prompt: **Save changes?** / **Don't Save**.
2. **Choose a Style**: Film, TV Drama, Anime, Pixar, Cartoon, Fantasy, Noir, Cyberpunk, Custom. Or skip: style previews after the screenplay.
3. Describe the plot; **Generate** or **Auto** (“Auto-generate all frames, then pause for review before videos”).
4. Checkpoints (unless Auto): **Review Screenplay** → **Review Style Prompts** → **Continue → Generate Style Previews** → **Use This Style** → **Review Character Prompts** → **Continue → Generate Portraits** → **Review Scene Prompts** → **Continue → Generate Scene Images** → per-shot **Review Shot N Opening Keyframe** → **Review All Keyframes** → optional **Auto-generate all videos after review** → **Generate Videos**.
5. **Production Complete!** “N shots added to the timeline.”

Also: **Prompt Log**, **Progress Log**, **Dump to /tmp** (debug). **Pause** / **Skip** / **Retry Failed**.

Limitation until you <Link to="/knoxstudio/sign-in">sign in</Link>: frame previews stay unavailable. Leftover UI copy may still say “add one in SI Settings → Sub-Models” — that tab is gone; sign-in fills the catalog.
