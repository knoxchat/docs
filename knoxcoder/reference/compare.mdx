# Compare

Four names people mix up. Only the first row is this tab.

| Product | What it is | Data dir | Where the docs live |
|---|---|---|---|
| **KnoxCoder + Knox Agent** | Desktop editor with builtin `vscode.knox` | `~/.knoxcoder` | **This tab** (`/knoxcoder`) |
| **Marketplace Knox** (`knoxchat.knoxchat`) | VSIX for **vanilla VS Code** | `~/.knox` | Not here. **Blocked** inside KnoxCoder — do not install it in this app |
| **Knox.Chat API** | HTTP API at `api.knox.chat` | Cloud | Docs / API Reference tabs |
| **KnoxCode** | Older/separate agent mentioned in some blog posts | — | **Wrong product.** Do not copy those posts into this guide |

## Builtin vs marketplace VSIX

| | KnoxCoder builtin | Marketplace VSIX |
|---|---|---|
| Install | Ships in the app | Open VSX / VSIX |
| Id | `vscode.knox` | `knoxchat.knoxchat` |
| Home | `~/.knoxcoder` | `~/.knox` |
| Chat UI | Native workbench pane | Not this editor |
| MCP in 2.2 | **No** | Out of scope here |
| Uninstall | Cannot; **Disable** only | Uninstall the VSIX |

No automatic copy from `~/.knox` into `~/.knoxcoder`.

## KnoxCoder vs Knox.Chat API

KnoxCoder can **call** KnoxStudio / Knox.Chat as a **model provider** after you sign in. That does not make the editor the API. Multimodal generation, Knox-MS **cloud** memory, and OpenAPI live under **Docs** — different product, and Knox-MS may talk about vectors. KnoxCoder Memory Brain never does.

## For extension authors

Other extensions should not treat `vscode.knox` as a public API to drive. This guide is for **people using the editor**.
