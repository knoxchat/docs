# 零输出补偿保险

Knox Chat 提供零输出生成保护，确保用户不会因失败或空响应而被收费。如果响应不包含任何输出 token 且生成原因为空或发生错误，您将不会为该请求付费——即使底层供应商收取了快速处理费用。

## 工作原理

零输出生成保护会自动应用于所有模型和供应商的所有请求。如果响应满足以下任一条件，您的账户将不会被扣除任何费用：

* 响应包含零个输出 token，且生成原因为空白/空。
* 响应的生成原因包含错误信息。

## 查看受保护的请求

在您的 Knox Chat 账户 [**活动记录**](https://knox.chat/activity) 页面中，受零输出生成保险保护的请求将显示扣除金额为零。
