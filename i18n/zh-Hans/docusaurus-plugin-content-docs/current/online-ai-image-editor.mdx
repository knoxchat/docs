### 8. 多轮图像上下文

**使用先前的图像作为上下文**，实现无缝编辑工作流。

| ![](/img/image-generation/ai-img-23.png) |
|-|

#### 上下文模式：

| 模式 | 描述 | 适用场景 |
|------|-------------|----------|
| **No Context** | 全新生成 | 创建新图像 |
| **Use Previous One** | 以上一张图像为上下文 | 继续单次编辑 |
| **Use Previous Ten** | 以最近 10 张图像为上下文 | 复杂的多图编辑 |

#### 工作原理：

启用上下文后：
1. AI 自动接收先前的图像
2. 你的编辑将应用于这些图像
3. 生成保持一致性的编辑版本

#### 使用方法：

**启用上下文：**
1. 找到"Image Context"选择器（在 Aspect Ratio 旁边）
2. 选择你的模式
3. 输入编辑内容
4. AI 会将编辑应用于上下文图像

**示例工作流：**
```
Turn 1: "Portrait of a man in a suit"
→ Context: No Context
Note: Select Aspect Ratio 2:3 -> 832x1248 for best practice

3. Quick Edit → "Better Light"
4. Style Gallery → "Cinematic"

### 工作流 3：风格探索

**目标：** 在同一图像上尝试多种风格

```
1. Generate base image
2. Context → "Use Previous One"
3. Style Gallery → Try "Oil Painting"
4. Context still on → Try "Watercolor"
5. Context still on → Try "Anime"

7. Star favorites

**目标：** 编辑图像的特定区域

```
1. Click image to open viewer
2. Select ✏️ Draw tool
3. Circle the area to edit
4. Close viewer
5. Type: "Make this area [your edit]"
6. AI focuses on marked region
7. Compare before/after
```

### 工作流 5：迭代精修

**目标：** 通过多次编辑完善图像

```
1. Generate starting image
2. Context → "Use Previous One" (keep ON)
3. Edit 1: "Make colors more vibrant"
4. Edit 2: "Add more contrast"
5. Edit 3: "Soften the lighting"
6. Edit History → Review all versions
7. Compare version 2 vs version 4
8. Download best version
```
