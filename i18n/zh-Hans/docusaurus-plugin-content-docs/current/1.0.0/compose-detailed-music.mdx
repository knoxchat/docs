请求体与 [`POST /v1/music`](/1.0.0/compose-music) 相同，另可选用 `with_timestamps` 和 `with_waveform_visual`。返回音频和元数据，而不仅是原始文件。按 **每生成分钟 `$0.20`** 计费。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| output_format | String | 否 | 默认 `auto`。允许值：`auto`, `mp3_48000_128`, `mp3_48000_192`, `mp3_48000_240`, `mp3_48000_320`, `mp3_22050_32`, `mp3_24000_48`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`, `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json`。 |

### 请求体

字段与 [作曲](/1.0.0/compose-music) 相同，另外：

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| with_timestamps | Boolean | 否 | 包含词级时间戳。默认 `false`。 |
| with_waveform_visual | Boolean | 否 | 包含波形可视化。默认 `false`。 |

## cURL 示例

```shell
curl -X POST "https://api.knoxstudio.ai/v1/music/detailed?output_format=mp3_44100_128" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
  "model_id": "music_v2_5",
  "prompt": "一段电影感管弦主题",
  "music_length_ms": 30000,
  "with_timestamps": true
}'
```

## 响应

### 成功响应 (200)

JSON（或 multipart，取决于上游）包含音频负载和作曲元数据。`with_timestamps` 为 true 时包含词级时间。

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
