修补源片段。`text`、`speaker_id`、`start_s`、`end_s` 至少提供一个。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| project_id | String | 是 | 配音项目 ID。 |
| segment_id | String | 是 | 片段 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| text | String | 否 | 替换后的源文本。 |
| speaker_id | String | 否 | 替换后的说话人 ID。 |
| start_s | Number | 否 | 开始时间。若发送任一时间，时长必须为 0.1–25 秒。 |
| end_s | Number | 否 | 结束时间。 |

## cURL 示例

```shell
curl -X PATCH https://api.knoxstudio.ai/v1/dubbing/project/proj_123/transcript/segment/seg_789 \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"text":"Hello there, friend"}'
```

## 响应

### 成功响应 (200)

更新后的片段 JSON。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
