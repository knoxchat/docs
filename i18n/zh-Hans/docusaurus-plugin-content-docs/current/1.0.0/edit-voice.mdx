更新音色。必须提供 `name`。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| voice_id | String | 是 | 音色 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| name | String | 是 | 显示名称。 |
| files | File | 否 | 可选替换样本。 |
| description | String | 否 | 转发的描述。 |
| labels | String | 否 | 标签的 JSON 对象或 JSON 字符串。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/voice_id/edit \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "name=Studio Narrator"
```

## 响应

### 成功响应 (200)

更新后的音色 JSON。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
