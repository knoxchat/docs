添加另一种配音语言。按 **片源时长 × 模型费率** 计费。`target_language` 为 BCP-47 标签。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| project_id | String | 是 | 父配音项目 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| target_language | String | 是 | BCP-47 语言标签。 |
| voice_settings.cloning_strength | Integer | 否 | 0–10。 |
| translations | Object | 否 | 可选的按片段译文。最多 20,000 条。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/dubbing/project/proj_123/language \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"target_language":"ja","voice_settings":{"cloning_strength":5}}'
```

## 响应

### 成功响应 (200)

新语种目标的 JSON（`language_id`、`status`）。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
