列出可访问的项目。**不计费**。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| status | String | 否 | `queued`、`preparing`、`processing`、`ready`、`failed` 之一。 |
| sort_direction | String | 否 | `ASCENDING` 或 `DESCENDING`。 |
| page_size | Integer | 否 | 原样转发到上游。文档默认 20，最大 100。 |
| cursor | String | 否 | 分页游标，原样转发到上游。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET "https://api.knoxstudio.ai/v1/dubbing/project?status=ready&sort_direction=DESCENDING" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## 响应

### 成功响应 (200)

项目 JSON 列表（`project_id`、`status`、`model_id`、媒体元数据）。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
