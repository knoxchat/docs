根据上传视频生成匹配的配乐。视频按顺序合并。最多 **10** 个视频，合计 **200MB**，multipart 负载 **210MB**。按 **`$0.20`/分钟** 计费。`output_format` 使用分轨允许列表（无 `auto`，无 48 kHz MP3）。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| output_format | String | 否 | 允许值：`mp3_22050_32`, `mp3_24000_48`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`, `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data`。 |

### 请求体（`multipart/form-data`）

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| videos | Files | 是 | 一个或多个视频文件（`videos` FormData 数组）。按顺序合并。 |
| description | String | 否 | 音乐描述，最多 1000 字符。 |
| tags | List of Strings | 否 | 风格标签，最多 10 个（例如 `upbeat`、`cinematic`）。 |
| model_id | String | 否 | `music_v1`、`music_v2` 或 `music_v2_5`。 |
| sign_with_c2pa | Boolean | 否 | 为 MP3 输出签名 C2PA。 |

## cURL 示例

```shell
curl -X POST "https://api.knoxstudio.ai/v1/music/video-to-music?output_format=mp3_44100_128" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "videos=@clip1.mp4" \
     -F "videos=@clip2.mp4" \
     -F "description=温暖的电影配乐，无人声" \
     -F "tags=cinematic" \
     -F "tags=orchestral" \
     -F "model_id=music_v2_5" \
     -o score.mp3
```

## 响应

### 成功响应 (200)

生成的音频文件。`Content-Type` 随 `output_format`（默认 MP3）。

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
