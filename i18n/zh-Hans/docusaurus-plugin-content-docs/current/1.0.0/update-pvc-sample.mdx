可选裁剪、说话人选择和去噪。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| voice_id | String | 是 | 音色 ID。 |
| sample_id | String | 是 | 样本 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| remove_background_noise | Boolean | 否 | 在样本中分离人声。 |
| selected_speaker_ids | List of Strings | 否 | 分离后要保留的说话人。 |
| trim_start_time | Integer | 否 | 裁剪起点（毫秒或采样，原样转发）。 |
| trim_end_time | Integer | 否 | 裁剪终点。 |
| file_name | String | 否 | 可选显示名称。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/pvc/voice_id/samples/sample_id \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"remove_background_noise":true}'
```

## 响应

### 成功响应 (200)

更新后的样本 JSON。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
