列出你可以访问的微调（自己的、工作区共享的、以及精选的）。此读取 **不计费**。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| cursor | String | 否 | 上一页响应中的下一页游标。 |
| page_size | Integer | 否 | 默认 `50`，最大 `150`。 |
| visibility | String | 否 | `private`、`workspace` 或 `public`。 |
| created_by | String | 否 | `self`、`workspace` 或 `elevenlabs`。 |
| sort | String | 否 | `created_at`（默认）或 `name`。 |
| sort_direction | String | 否 | `asc` 或 `desc`（默认 `desc`）。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET "https://api.knoxstudio.ai/v1/music/finetunes?page_size=50&sort=created_at&sort_direction=desc" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## 响应

### 成功响应 (200)

`finetunes` 数组；若还有更多结果则包含下一页 `cursor`。

### 微调对象

| id | string | 微调 ID。 |
| name | string | 显示名称（5–200 字符）。 |
| tags | array of strings | 关联标签。 |
| model_id | string | 基础音乐模型。 |
| created_at | string | UTC 时间戳。 |
| visibility | string | `private`、`workspace` 或 `public`。 |
| created_by | string | `self`、`workspace` 或 `elevenlabs`。 |
| status | string | `pending`、`in_progress`、`completed`、`failed`、`blocked`。 |
| training_progress | number | 0.0–1.0。 |
| primary_genre | string | 主风格。 |
| failure_reason | string | `audio_processing_failed`、`copyright_violation` 或 `training_failed`。 |

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
