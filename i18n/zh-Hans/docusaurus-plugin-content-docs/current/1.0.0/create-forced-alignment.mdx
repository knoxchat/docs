`file` 和 `text` 均为必填。文件最大 **3GB**，音频 **100ms–10 小时**，转写最多 **675,000** 字符。按 **每小时 `$0.27`** 计费。指南：[强制对齐](/forced-alignment)。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| enable_logging | Boolean | 否 | 默认 `true`。`false` 请求零保留模式。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| file | File | 是 | 要对齐的音频文件。 |
| text | String | 是 | 要对齐的转写。最多 675,000 字符。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/forced-alignment \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "file=@speech.wav" \
     -F "text=Hello from Knox. This is forced alignment."
```

## 响应

### 成功响应 (200)

JSON：

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| characters | array | `text`、`start`、`end`，可选 `loss`。 |
| words | array | `text`、`start`、`end`，可选 `loss`。 |

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
