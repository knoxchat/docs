<MethodEndpoint
  method={"patch"}
  path={"https://api.knoxstudio.ai/v1/dubbing/project/{project_id}/transcript/segments"}
>
</MethodEndpoint>

`segments` 必须包含 **1–500** 条。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| project_id | String | 是 | 配音项目 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| segments | Object | 是 | `segment_id` 到补丁对象（`text`、`speaker_id`、`start_s`、`end_s`）的映射。1–500 条。 |

## cURL 示例

```shell
curl -X PATCH https://api.knoxstudio.ai/v1/dubbing/project/proj_123/transcript/segments \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"segments":{"seg_789":{"text":"Updated line"}}}'
```

## 响应

### 成功响应 (200)

批量结果 JSON。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
