必须提供 `name` 和 `language`。可选 `labels` 必须是对象或 JSON 字符串。**不计费**。

## 请求

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| name | String | 是 | 音色名称。 |
| language | String | 是 | 音色语言。 |
| description | String | 否 | 可选描述。 |
| labels | Object or String | 否 | 元数据标签。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/pvc \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"name":"Pro Narrator","language":"en"}'
```

## 响应

### 成功响应 (200)

新建 PVC 音色 JSON，包含 `voice_id`。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
