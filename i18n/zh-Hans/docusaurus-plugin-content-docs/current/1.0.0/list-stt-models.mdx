返回 STT 模型。将 `id` 用作 `model_id`。批量默认 `scribe_v2`；WebSocket 默认 `scribe_v2_realtime`。见 [语音转文本](/speech-to-text)。

认证是可选的（公开目录每分钟 **60** 次，缓存 **5** 分钟；携带 token 时过滤列表）。

## 请求

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 否 | 可选 `Bearer <token>`。公开目录请省略。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET https://api.knoxstudio.ai/v1/speech-to-text/models
```

## 响应

```json

      "canonical_slug": "scribe_v2",

      "pricing": {
```

同时列出：`scribe_v2_realtime`（`per_hour`：`0.44`）。

### 响应 Schema

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| data[].id | string | 作为 `model_id` 发送。 |
| data[].pricing.per_hour | string | 每音频小时的美元价格。 |
| data[].pricing.entity_detection | string | 附加项每小时美元（`0.12`）。 |
| data[].pricing.keyterm_prompting | string | 附加项每小时美元（`0.10`）。 |

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
