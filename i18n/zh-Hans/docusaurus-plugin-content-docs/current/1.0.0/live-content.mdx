下载创建时带 `"store": true` 的 Live 会话录音。文件是**立体声 WAV**：主叫输入在左声道，助手输出在右声道。

录音在创建后保留 **30 天**。只有会话所有者可以下载。见 [GPT-Live](/live) 指南。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| session_id | String | 是 | 已存储的 Live 会话 id。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer sk-…`。 |

## cURL 示例

```shell
curl -L https://api.knox.chat/v1/live/sessions/sess_…/content \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -o session.wav
```

## 响应

`200`，`Content-Type: audio/wav`（或上游类型），以及 `Content-Disposition: attachment; filename="{session_id}.wav"`。响应体为流式传输。

## 错误响应

| 状态 | 何时 |
| ---- | ---- |
| `401` | 缺少或无效的 Knox API key。 |
| `403` | Token 未被授权使用 `gpt-live-1`。 |
| `404` | 会话不存在、不属于你、未存储（`store: false`），或超过 30 天。 |
| `502` | 无法从 Live 提供商获取录音。 |
