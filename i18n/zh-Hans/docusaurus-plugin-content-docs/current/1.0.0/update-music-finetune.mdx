修补元数据。可见性只能设为 `private` 或 `workspace`。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| finetune_id | String | 是 | 微调 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json`。 |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| name | String | 否 | 更新后的名称，5–200 字符。 |
| tags | List of Strings | 否 | 替换后的标签集。 |
| primary_genre | String | 否 | 更新后的风格。 |
| visibility | String | 否 | `private` 或 `workspace`。 |

## cURL 示例

```shell
curl -X PATCH https://api.knoxstudio.ai/v1/music/finetunes/ftn_123 \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
  "name": "工作室民谣集 v2",
  "visibility": "workspace"
}'
```

## 响应

### 成功响应 (200)

更新后的微调对象（schema 与 [获取音乐微调](/1.0.0/get-music-finetune) 相同）。

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
