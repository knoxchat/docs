列出语种目标。**不计费**。状态：`queued`、`processing`、`completed`、`stale`、`failed`。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| project_id | String | 是 | 父配音项目 ID。 |

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| status | String | 否 | `queued`、`processing`、`completed`、`stale`、`failed` 之一。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET https://api.knoxstudio.ai/v1/dubbing/project/proj_123/language \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## 响应

### 成功响应 (200)

语种目标 JSON 列表。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
