IVC 创建。必须提供 `name` 和 `files`。样本上传包装后不超过 **210MB**。**不计费**。指南：[音色](/voices)。

## 请求

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| name | String | 是 | 音色名称。 |
| files | File | 是 | 用于克隆的音频。多个文件重复该字段。 |
| description | String | 否 | 可选描述，原样转发。 |
| labels | String | 否 | JSON 对象或 JSON 字符串。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/add \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "name=Studio Narrator" \
     -F "files=@sample1.wav" \
     -F "files=@sample2.wav"
```

## 响应

### 成功响应 (200)

新建音色 JSON，包含 `voice_id`。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
