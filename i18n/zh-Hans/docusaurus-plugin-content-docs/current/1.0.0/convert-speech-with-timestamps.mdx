请求体与 [生成语音](/1.0.0/convert-speech) 相同。返回含 base64 音频和字符对齐的 JSON，而不是原始字节。允许 WAV 格式。按字符计费。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| voice_id | String | 是 | ElevenLabs 音色 ID。 |

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| enable_logging | Boolean | 否 | 默认 `true`。`false` 请求零保留模式。 |
| optimize_streaming_latency | Integer | 否 | 已弃用。0–4 延迟/质量权衡。 |
| output_format | String | 否 | 默认 `mp3_44100_128`。格式为 `codec_sample_rate_bitrate`。 |

允许的 `output_format`（含 WAV）：`alaw_8000`, `mp3_22050_32`, `mp3_24000_48`, `mp3_44100_128`, `mp3_44100_192`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `opus_48000_128`, `opus_48000_192`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`, `pcm_48000`, `pcm_8000`, `ulaw_8000`, `wav_16000`, `wav_22050`, `wav_24000`, `wav_32000`, `wav_44100`, `wav_48000`, `wav_8000`。

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json`。 |

### 请求体

字段与 [生成语音](/1.0.0/convert-speech) 相同。

## cURL 示例

```shell
curl -X POST "https://api.knoxstudio.ai/v1/text-to-speech/21m00Tcm4TlvDq8ikWAM/with-timestamps" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
  "text": "把这行同步到字幕。",
  "model_id": "eleven_multilingual_v2"
}'
```

## 响应

### 成功响应 (200)

| audio_base64 | string | Base64 编码的音频。 |
| alignment | object | 原文的字符时间：`characters`、`character_start_times_seconds`、`character_end_times_seconds`。 |
| normalized_alignment | object | 规范化文本的同样结构。 |

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
