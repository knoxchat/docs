删除 PVC 样本。**不计费**。

## 请求

### 路径参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| voice_id | String | 是 | 音色 ID。 |
| sample_id | String | 是 | 样本 ID。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X DELETE https://api.knoxstudio.ai/v1/voices/pvc/voice_id/samples/sample_id \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## 响应

### 成功响应 (200)

删除成功。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
