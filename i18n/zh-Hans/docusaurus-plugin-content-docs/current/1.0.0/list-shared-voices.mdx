公开音色库列表。**不计费**。默认 `page_size` 30，最大 100。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| page_size | Integer | 否 | 1–100，默认 30。 |
| page | Integer | 否 | 页码。 |
| category | String | 否 | `professional`、`famous`、`high_quality`。 |
| sort | String | 否 | `created_date`、`usage_character_count_1y`、`trending`、`cloned_by_count`。 |
| min_notice_period_days | Integer | 否 | 最短通知期筛选。 |
| featured | Boolean | 否 | 仅精选。 |
| include_custom_rates | Boolean | 否 | 包含自定义费率。 |
| include_live_moderated | Boolean | 否 | 包含实时审核音色。 |
| reader_app_enabled | Boolean | 否 | 启用阅读器应用的音色。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET "https://api.knoxstudio.ai/v1/shared-voices?page_size=30&sort=trending" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## 响应

### 成功响应 (200)

分页共享音色 JSON（`public_owner_id`、`voice_id`、`name`）。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
