创建项目。必须提供 `file` 或 `source_url` 二者之一。源媒体最大 **3 GiB**。**第一种目标语言**按片源时长计费（`dubbing_v2` 每分钟 `$2.25`，`dubbing_v1` 每分钟 `$0.38`）。指南：[配音](/dubbing)。

## 请求

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data or application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| file | File | 否 | 源媒体。必须与 `source_url` 二选一。最大 3 GiB。 |
| source_url | String | 否 | 源媒体的公开 HTTP(S) URL。 |
| model_id | String | 否 | `dubbing_v2`（默认）或 `dubbing_v1`。 |
| source_language | String | 否 | BCP-47 标签。提供 `transcript` 时**必填**。 |
| target_language | String | 否 | 第一种配音语言的 BCP-47 标签。 |
| transcript | File | 否 | 可选源转写。最大 4MB。需要 `source_language`。 |
| reference | String | 否 | 可选备注，最多 500 字符。 |
| keyterms | List of Strings | 否 | 最多 1000 个词，每项 50 字符 / 5 个词。不允许 `<>{}[]\`。 |
| webhook_ids | List of Strings | 否 | 最多 3 个非空 webhook ID。 |

## cURL 示例

```shell
curl -X POST https://api.knoxstudio.ai/v1/dubbing/project \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "file=@episode.mp4" \
     -F "model_id=dubbing_v2" \
     -F "source_language=en" \
     -F "target_language=zh-CN"
```

## 响应

### 成功响应 (200)

JSON，包含 `project_id`。轮询 [获取配音项目](/1.0.0/get-dubbing-project) 直到 `ready` 或 `failed`。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
