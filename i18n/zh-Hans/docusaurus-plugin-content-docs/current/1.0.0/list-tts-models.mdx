返回 TTS 模型。将 `id` 用作合成/流式/WebSocket 端点的 `model_id`。见 [文本转语音](/text-to-speech)。

认证是可选的（公开目录每分钟 **60** 次，缓存 **5** 分钟；携带 token 时过滤列表）。

## 请求

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 否 | 可选 `Bearer <token>`。公开目录请省略。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET https://api.knoxstudio.ai/v1/text-to-speech/models
```

## 响应

### 成功响应 (200)

```json
{
  "data": [
    {
      "id": "eleven_multilingual_v2",
      "canonical_slug": "eleven_multilingual_v2",
      "name": "ElevenLabs Multilingual v2",
      "created": 1690848000,
      "description": "Stable, lifelike narration in 29 languages. Default TTS model. Up to 10,000 characters per request.",
      "chinese_description": "29 种语言的稳定拟真朗读，默认 TTS 模型，单次最多 10,000 字符。",
      "max_characters": 10000,
      "pricing": {
        "per_thousand_characters": "0.15"
      },
      "architecture": {
        "modality": "audio",
        "input_modalities": ["text"],
        "output_modalities": ["audio"],
        "tokenizer": "elevenlabs"
      }
    }
  ]
}
```

同时列出：`eleven_v3`（`$0.15` / 千字符，5,000 字符）、`eleven_v3_conversational`、`eleven_flash_v2_5`、`eleven_flash_v2`、`eleven_turbo_v2_5`、`eleven_turbo_v2`（低延迟模型 `$0.10` / 千字符）。

### 响应 Schema

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| data[].id | string | 作为 `model_id` 发送。 |
| data[].max_characters | integer | 单次请求字符上限。 |
| data[].pricing.per_thousand_characters | string | 每 1,000 字符的美元价格。 |

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
