返回人声分离模型。将 `id` 用作 `model_id`。默认 `audio_isolation`。见 [人声分离](/voice-isolator)。

认证是可选的（公开目录每分钟 **60** 次，缓存 **5** 分钟；携带 token 时过滤列表）。

## 请求

此端点不需要请求参数。

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 否 | 可选 `Bearer <token>`。省略则返回公开目录。也接受 `xi-api-key`。 |

## cURL 示例

```shell
curl -X GET https://api.knoxstudio.ai/v1/audio-isolation/models
```

### 响应 Schema

| 名称 | 类型 | 描述 |
| ---- | ---- | ---- |
| data[].id | string | 用作 `model_id`。始终为 `audio_isolation`。 |
| data[].max_duration_seconds | integer | `3600`（1 小时）。 |
| data[].pricing.per_minute | string | 每音频分钟美元价格（`0.17`）。 |

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
