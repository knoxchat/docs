将混音拆成音轨（人声、鼓、贝斯等）。延迟随文件时长增加。按估算时长 **每分钟 `$0.20`** 计费。Multipart 最大 **210MB**。此处 **不能** 使用 `auto` 和 48 kHz MP3 阶梯作为 `output_format`。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| output_format | String | 否 | 允许值：`mp3_22050_32`, `mp3_24000_48`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`, `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`。 |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `multipart/form-data`。 |

### 请求体（`multipart/form-data`）

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| file | File | 是 | 要分轨的混音。 |
| stem_variation_id | String | 否 | 分轨变体预设。 |
| sign_with_c2pa | Boolean | 否 | 为 MP3 音轨签名 C2PA。 |

## cURL 示例

```shell
curl -X POST "https://api.knoxstudio.ai/v1/music/stem-separation?output_format=mp3_44100_128" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "file=@mix.mp3" \
     -o stems.zip
```

## 响应

### 成功响应 (200)

按请求格式打包的音轨 ZIP 压缩包。

## 错误响应

校验失败返回 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未携带 `Upgrade: websocket` 访问 WebSocket 路径。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源不存在。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
