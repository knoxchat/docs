根据 `text` 生成片段。时长 **0.5–30 秒**。按 **每分钟 `$0.17`** 计费（省略 `duration_seconds` 时先按 **5 秒**估算）。指南：[音效生成](/sound-effects)。

## 请求

### 查询参数

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| output_format | String | 否 | 允许值：`mp3_22050_32`, `mp3_24000_48`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`, `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`, `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`. WAV and `mp3_48000_*` are not allowed. |

### 请求头

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| Authorization | String | 是 | `Bearer <token>` Knox API key。也接受 `xi-api-key`。 |
| Content-Type | String | 是 | `application/json` |

### 请求体

| 名称 | 类型 | 必填 | 描述 |
| ---- | ---- | ---- | ---- |
| text | String | 是 | 要转换成音效的提示词。 |
| model_id | String | 否 | 若设置必须为 `eleven_text_to_sound_v2`。默认 `eleven_text_to_sound_v2`。 |
| duration_seconds | Number | 否 | 0.5–30。可选；模型也可自行选择时长。 |
| prompt_influence | Number | 否 | 0–1。默认 0.3。值越高越贴近提示词。 |
| loop | Boolean | 否 | 无缝循环。仅对 `eleven_text_to_sound_v2` 有效。 |

## cURL 示例

```shell
curl -X POST "https://api.knoxstudio.ai/v1/sound-generation?output_format=mp3_44100_128" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -o sfx.mp3 \
     -d '{
  "text": "Spacious cinematic braam",
  "duration_seconds": 4.5,
  "prompt_influence": 0.3,
  "model_id": "eleven_text_to_sound_v2"
}'
```

## 响应

### 成功响应 (200)

生成的音频文件。`Content-Type` 随 `output_format` 变化。

## 错误响应

校验失败使用 HTTP `422`：

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

其他错误使用 `{ "detail": "message" }`。

| 状态 | 何时 |
| ---- | ---- |
| `400` | 未升级 WebSocket 就访问 WebSocket 端点。 |
| `401` | 缺少或无效的 API key。 |
| `402` | 余额不足。 |
| `403` | Token 无权使用该模型。 |
| `404` | 资源未找到。 |
| `422` | 校验错误。 |
| `429` | 超出速率限制。 |
| `500` | 服务器内部错误。 |
