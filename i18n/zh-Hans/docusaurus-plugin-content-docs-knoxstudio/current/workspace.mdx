# 工作区

主窗口是原生工作室，不是浏览器标签。布局尺寸、缩放、检查器标签和上次中央视图会写进应用偏好。

## 面板

| 面板 | 默认 | 范围 | 开关 |
|---|---|---|---|
| **Explorer**（左） | `~/.knoxmedia` 文件树 | 180–720 px | 显示 → 左侧栏，标题栏按钮 |
| **画布 / 剧本**（中） | 剩余空间 | — | 标题栏标签，<kbd>⌘4</kbd> 剧本 |
| **检查器**（右） | 275 px | 250–380 | <kbd>⌘1</kbd> |
| **SI Agent**（右） | 360 px | 最小 320，最大窗口 50% | <kbd>⌘2</kbd> |
| **传输条 + 时间线**（下） | 时间线 200 px | 106–600 | 显示 → 底栏 |

检查器和 Agent 共用右侧栏——一次只显示一个。<kbd>⌘3</kbd> 打开 Agent 坞里的 **角色**。

## 标题栏

左：Explorer 开关、**画布** / **剧本** 标签、当前中央视图的弹出 HUD。中：窗口标题。右：检查失败时的更新芯片、主题、语言（EN / 中）、底栏、Agent、检查器、偏好设置（在偏好设置控件上右键打开 **项目** 页）。

## 传输条

时间线上方：

撤销 / 重做（工具提示显示步数和大约 MB）· 新建 / 保存 / 打开 · 到开头 · 回退 1 秒 · 播放 / 暂停 · 前进 1 秒 · 到结尾 · 循环 · 播放质量 · 安全区 · **录制** · 录制设置 · 实时采集指示（麦 / 系统音频 / 摄像头）· 添加媒体 · 缺失媒体徽章 · 导出。

## 时间线工具栏

编辑模式芯片（<kbd>Tab</kbd>）· 离开嵌套 · 工具芯片（选择 / 刀片 / 滑动 / 磁性）· 吸附 · 曲线编辑器 · 导入 @Head 对 @Start · 图像生成（合并所选静帧）· 播放头时间码 · 缩放 − / 滑杆 / + · 缺失媒体芯片 · 轨道数 + 时长 · 弹出时间线 HUD。

## 检查器标签

上次打开的标签会记住。

| 标签 | 用途 |
|---|---|
| **片段** | 名称、颜色、锁定 |
| **音频** | 混音台、片段音量 / 声像 / 淡化、EQ、闪避 |
| **操作（视频）** | 速度、倒放、定格、慢动作、运动模糊、**裁切、混合、跟随、自动关键帧、对齐**、运动预设 |
| **滤镜** | 调色、模糊、锐化、暗角、LUT、曲线、遮罩、色度键、颗粒、效果栈 |
| **注释** | 工具、样式、时间、模板 |

## 菜单

**KnoxStudio** · **文件**（新建 / 打开 / 打开最近 / 保存 / 另存为 / 录制设置 / 项目设置 / 导出）· **编辑** · **显示**（侧栏、检查器、Agent、画布、剧本、主题、语言、键盘快捷键）· **播放** · **窗口** · **帮助**（快捷键、调试控制台、错误日志、检查更新）。程序坞菜单：新建、打开、打开最近。

## 伴随 HUD

浮动玻璃窗口：对话、Explorer、检查器、时间线、画布、剧本。另外还有 **Voice Director** 圆球。圆球亮着时，伴随窗口一起开着，并绑定和编辑器相同的 NLE 快捷键。<Link to="/knoxstudio/production/voice-director">Voice Director</Link>。

## 空状态

- **欢迎卡：** 新建、打开、最近（钉住 / 取消）、录制、导入、对 SI 说话。
- **画布为空：** 录制 / 添加媒体。
- **剧本欢迎：** 从 Explorer 打开或 **新建剧本**。

## 播放质量

下拉：**自动 / 代理 / 全质量**。导出始终用原始媒体。播放时可以跳过调色/效果以保证实时；暂停看全质量。
