# 预设与质量

## 内置预设

Screen Tutorial 1080p · Course Master 4K · Web Preview 720p · TikTok / Reels 9:16 · YouTube 1080p · YouTube 4K · Square 1080 · Twitter / X 16:9 · Animated GIF Small · Audio MP3 320 kbps · Audio WAV。

项目尺寸匹配竖屏或方形预设时会出现社交画布提示。你可以 **保存自己的** 预设。

## 分辨率

640×480、1280×720、1920×1080、3840×2160、源的 25 / 50 / 75 / 100%、自定义。偶数字（编码器要求）。

## 码率和质量

码率是 **上限**。质量才是主旋钮。

| 码率预设 | 大约 |
|---|---|
| 自动 | 由分辨率推导 |
| 低 | 2 Mbps |
| 中 | 5 Mbps |
| 高 | 8 Mbps |
| 超 | 15 Mbps |
| 无损 | 30 Mbps |
| 自定义 | |

**质量：** 最快 / 正常 / 最慢——映射到 VideoToolbox q、x264/x265 CRF，或 ProRes 422 LT / 422 HQ / 4444。

**编码器：** 自动（macOS 上 VideoToolbox）/ 硬件 / 软件。

偏好设置 → 通用保存新导出对话框的 **导出默认值**（格式、帧率）。
