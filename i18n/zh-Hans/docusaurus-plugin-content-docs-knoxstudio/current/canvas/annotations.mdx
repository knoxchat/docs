# 注释

在画布上画。画布聚焦时用数字键选工具。注释在 **注释** 轨道上（前缀 N）。

## 工具

| 键 | 工具 |
|---|---|
| <kbd>V</kbd> | 选择 |
| <kbd>1</kbd> | 矩形 |
| <kbd>2</kbd> | 椭圆 |
| <kbd>3</kbd> | 箭头 |
| <kbd>4</kbd> | 直线 |
| <kbd>5</kbd> | 文字 |
| <kbd>6</kbd> | 手绘 |
| <kbd>7</kbd> | 高亮 |
| <kbd>8</kbd> | 标注 |
| <kbd>9</kbd> | 编号步骤 |
| <kbd>0</kbd> | 模糊区域（马赛克） |
| <kbd>⇧0</kbd> | 聚光（外部变暗） |

方向键微移；Shift 为 5 倍。**字幕** 是字幕轨道种类，不是数字工具——<Link to="/knoxstudio/canvas/captions">字幕</Link>。

## 模板

标注、下三分之一（自动左滑）、片头标题（自动淡入）、键盘提示、步骤徽章。检查器和 Editor 工具 `add_annotation_template`。

## 样式

填充、描边、不透明度、粗细、阴影、轮廓、圆角。文字：水平 / 垂直对齐、粗体 / 斜体 / 下划线、比例 / 等宽、系统字体名、行高、字距、轮廓宽度、阴影偏移 / 模糊、底板。字号 12–240。模糊块大小。标注尾巴。

## 标题动画

淡入、左 / 右 / 上滑、逐字出现、高亮出现、描边绘制。

## 时间

默认注释时长是项目设置（默认 **5 秒**）。淡入 / 淡出。关键帧：位置 X/Y、缩放、旋转、不透明度、TextReveal、TextHighlight、StrokeTrim。
