# 滤镜

检查器 **滤镜** 标签。应用到所选片段。Editor Agent 的 `apply_effect` / `set_effect_param` / `reorder_effect` 用同一套名字。

## 可应用的效果

| 效果 | 说明 |
|---|---|
| **调色** | 曝光、亮度、对比度、伽马、高光、阴影、饱和度、自然饱和度、色温、色相。预设芯片 **黑白 / 暖色 / 冷色**。同样的调色键也可以打成片段关键帧 |
| **高斯模糊** | |
| **锐化** | |
| **暗角** | |
| **3D LUT** | **选择 .cube** 会拷进项目 `luts/` 文件夹；有强度滑杆。没选时显示「未选择 LUT」 |
| **曲线** | 主 / R / G / B；阴影 / 中间调 / 高光 |
| **遮罩** | 椭圆 / 矩形 / 自由绘制；反转和羽化 |
| **色度键** | 绿或蓝；相似度和混合 |
| **颗粒** | |

**Wave** 出现在目录里，但 **不能应用**（`is_available` 为 false）。不要指望它会渲染。

## 效果栈

搜索、添加、**旁路**（眼睛）、重排、插入间隙。旁路把效果留在栈里但不渲染。Editor Agent 用同样的名字重排。

## 调整轨

轨道种类 **调整**（前缀 G）给 **下方** 视频调色，自己没有媒体。从时间线空隙 / 右键菜单 **添加调整轨**。

## 播放

画质为自动 / 代理时，重调色可能在实时播放里被跳过。暂停或设 **完整** 再看成片。导出始终是完整质量。
