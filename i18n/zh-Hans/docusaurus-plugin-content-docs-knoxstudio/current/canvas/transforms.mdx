# 变换与关键帧

每个可视片段都有变换。在画布上拖，或在检查器 **操作** 里改数值。对齐 / 分布和 **重置变换** 也在同一页。

## 画面栈（操作）

| 控件 | 作用 |
|---|---|
| **跟随** | 把这一层贴到另一片段的位置上（标签、画中画、标注）。**无** 会清除。自身 X/Y 变成相对父片段的偏移。 |
| **适配** | 包含（默认）、覆盖、拉伸、无。 |
| **裁切** | 左 / 上 / 右 / 下，源画面的归一化窗口。拖动画布上的 **内侧手柄**，或 **重置裁切**。 |
| **锚点** | 旋转和缩放绕此原点（中心为 50%）。<kbd>⌥</kbd>-拖画布上的十字准星可移动锚点而不移动画面。**重置锚点**。 |
| **位置 X/Y、缩放、旋转** | 画布手柄或滑杆。 |
| **混合** | 非摄像头片段：正常、正片叠底、滤色、叠加、增加、变暗、变亮。 |
| **不透明度** | 0–100%，可打关键帧。 |
| **速度** | 0.1–8× 预设和滑杆。倒放和定格在同一页——<Link to="/knoxstudio/timeline/clips">片段</Link>。 |
| **运动模糊** | 导出用 FFmpeg `tmix`。预览是廉价残影。 |

摄像头片段没有混合（改用画中画形状）；只有全帧摄像头才显示裁切。

## 自动关键帧

**自动关键帧**（操作 → 关键帧）：开启后，画布和检查器的更改会在播放头写入关键帧。关闭后，仅在该属性已有关键帧时写入。

可打关键帧的属性：位置 X/Y、缩放、旋转、不透明度、速度、音量、曝光、亮度、对比度、伽马、高光、阴影、饱和度、自然饱和度、色温、色相、模糊半径、暗角强度。

<kbd>⇧G</kbd> 打开 **曲线编辑器**。复制 / 粘贴 / 反转 / 清除作用在选中的菱形上（**复制关键帧**、**反转**）。位置 X/Y 打了关键帧时，画布上会画出运动路径。

**速度渐变：** 给速度打随时间变化的关键帧。音频按变速的 **平均** 速度拉伸（近似）。

仅注释的关键帧：TextReveal、TextHighlight、StrokeTrim——<Link to="/knoxstudio/canvas/annotations">注释</Link>。

## 区域缩放

<kbd>Z</kbd>，然后在画布上拖出一个矩形。片段会以缩放和位移动画铺满画面（进入 / 停留 / 退出时长在操作页、点击自动缩放旁边）。同一页可 **取消缩放**。

## 运动预设

Ken Burns、弹出、上淡、从左 / 右 / 下滑入、漂移、推进。时长 0.1–4 秒。Editor Agent 可用同样名字调用 `add_keyframe_preset`。

## 适配

| 模式 | 结果 |
|---|---|
| **包含** | 装进画布，其余留黑边。默认。 |
| **覆盖** | 铺满画布，裁切溢出。 |
| **拉伸** | 铺满，忽略比例。 |
| **无** | 原始尺寸：1 源像素 = 1 画布像素。 |
