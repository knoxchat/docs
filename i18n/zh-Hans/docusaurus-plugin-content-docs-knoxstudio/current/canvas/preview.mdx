# 预览画布

中央 **画布** 标签是 GPU 预览。它合成视频、摄像头、注释、点击/光标叠加、转场和调色——导出走同一条路径。

## 尺寸和背景

**偏好设置 → 通用**（新项目）和 **偏好设置 → 项目**（当前文档）：

| 设置 | 取值 |
|---|---|
| 画布尺寸 | 原始（匹配录制）、1280×720、1920×1080、2560×1440、3840×2160，或自定义 **宽 128–7680 × 高 96–4320** |
| 背景色 | 项目颜色，出现在信箱边上 |
| 帧率 | 默认 60。预设 24、25、29.97、30、48、50、59.94、60、120；自定义 1–120 |
| 图像时长 | 静帧 0.1–3600 秒（默认 5） |
| 静帧 Ken Burns | 项目开关 |

## 安全区

传输条开关，以及 <kbd>'</kbd> 切换标题/动作一对。叠加（不导出）：标题安全、动作安全、9:16、1:1。

## 摄像头层

一条里的实时摄像头：画中画 **圆**（默认）、**圆角矩形**、**方形**、**全画面**。在摄像头片段的检查器里。

## 播放对导出

播放质量 **自动 / 代理 / 全质量**。播放时可以跳过调色/效果以保证实时；**暂停** 看全质量。导出始终读原始媒体。

画布上的质量徽章会告诉你效果是否被跳过。

## 对齐

对齐 / 分布所选片段在检查器 **操作** 页、**重置变换** 旁边：左 / 中 / 右 / 上 / 中 / 下，相对选区或画布。两个及以上对齐；分布需要三个。变换手柄吸附到中心和边缘。

## 快速预览

在 Explorer 里点媒体文件会在画布上快速预览（音频 / 视频 / 图像）。可编辑文本则打开 **剧本**。
