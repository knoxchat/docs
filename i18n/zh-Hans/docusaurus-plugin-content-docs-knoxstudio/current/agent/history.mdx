# 对话历史

标题栏 **对话历史**。存在 `~/.knoxmedia/database/media_index.db`。

- **搜索对话...**
- **隐藏已归档** / **显示已归档**
- **选择** / **全选** / **删除** / **归档**
- 分组：今天、昨天、本周、本月
- 空：**还没有对话** / 「你的对话历史会出现在这里」
- 删除是 **永久** 的
- 流式时打开另一条：「还在生成回复…打开另一条对话会停掉它。」
- 第一轮之后智能标题（2–6 个词，和用户同一语言）。占位 **新对话**。草稿按对话恢复。
- 重新启动会恢复 **上一条对话和未发送的作曲栏草稿**。**新对话** 仍从空白开始。
- 生成卡片在输出文件被挪走时会显示 **缺失** / **在访达中显示**。

## 生成记录

提示、模型、供应商、时长、分辨率、角色、场景和输出路径存在本机。它们支撑 **变体** 和 Director 覆盖。没有专门的「生成历史」浏览器。

SQLite 里有 `provider_usage.total_cost_estimate`。本应用 **没有** 面向用户的费用 / 额度界面。用量记在 KnoxStudio 账号上。
