# 导出剧本

从剧本打开 **导出** 选择器（工具栏，或 <kbd>⌘⇧E</kbd> 导出 HTML）。选一种格式：

| 动作 | 快捷键 |
|---|---|
| **导出为 HTML** | <kbd>⌘⇧E</kbd> |
| **导出 Final Draft（FDX）** | 快捷键浮层列出（菜单） |
| **导出 Markdown（Knox 规范化副本）** | 选择器——Knox `[NAME]` 提示，不是逐字节原文件 |
| **打印预览** | <kbd>⌘P</kbd> |

文件写到 `~/.knoxmedia/screenplay/exports/`。打印预览是窗口里的 HTML——不是版式精确的校样。

**PDF：**「不直接支持 PDF 导出——已导出可打印的 HTML。打开它，选择 打印 → 存储为 PDF。」

方言感知解析让 Fountain 和文学体剧本在导出时保持场次顺序。重排时被压平的问题已在 1.7.3 修复。
