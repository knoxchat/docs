# 偏好设置

<kbd>⌘,</kbd>。五个标签。页脚：**重置**、**关闭**、**保存**。SI 账号 **不在这里**——用 <Link to="/knoxstudio/settings/agent-config">SI 配置</Link>。

## 通用

- 主题：深色 / 浅色
- 语言：英文 / 中文
- 启动时显示欢迎
- SI 对话：**回车发送**（关 = ⌘Enter）
- Voice Director：耳机、插话
- **桌面提醒**（序列、导出、生成）
- **项目默认：** 画布尺寸（原始 / 720p / 1080p / 1440p / 4K / 自定义）、帧率、在播放头导入
- **导出默认：** 格式、帧率
- **更新：** 自动检查；当前版本；检查 / 更新到…

## 辅助功能

- **减少动态效果**——跟随系统设置；可在应用内强制打开
- **增强对比度**——跟随系统设置 → 辅助功能 → 显示；加厚时间线芯片。不是第三套主题。可在应用内强制打开。
- **在本机保存崩溃报告**——错误日志 / 崩溃恢复需要

## 项目（当前文档）

分辨率、自定义宽×高、**背景色**、帧率、图像时长（0.1–3600 秒，默认 5）、静帧 Ken Burns、注释时长（默认 5）、播放质量 自动 / 代理 / 全质量、渲染缓存开/关 + 大小 + 清除。

**生成代理** — 先保存项目。把较轻的文件写进包内 `proxies/`，方便大文件 / 4K 的 **代理** 播放。导出仍用原片。生成前先重新链接缺失媒体。没有符合条件的文件时会提示「没有需要生成代理的大文件或 4K 媒体」。

**整合媒体** — 把已链接文件拷进包内 `media/`，方便带走项目。先重新链接缺失文件。通知：「已将媒体整合到项目包」。

在标题栏偏好设置控件上右键可跳到这一页。

## 录制

屏幕、麦、系统音频、摄像头、倒计时、倒计时秒数（1–60）、帧率、光标、点击、点击效果、左右颜色、半径、时长。<Link to="/knoxstudio/record/screen">录制</Link>。

## 设备

权限芯片、FFmpeg 捆绑 / 系统 / 缺失、屏幕 + 窗口选择、麦、系统音频、摄像头预览、**刷新设备**。

布局、HUD 窗位、检查器分区开合、时间线缩放和上次对话 id 会写进应用偏好，这些标签上没有单独控件。
