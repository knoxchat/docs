# SI 配置

菜单 **KnoxStudio → SI 配置…** 或 Agent 齿轮。标题 **SI 配置**，副标题 **账号、生成与执行默认值**。

**只有一页。** 旧的 Manager / Editor / 子模型标签文案还在翻译里，但 **不会渲染**。用 KnoxStudio 登录是唯一连接方式——粘贴 API 密钥已在 1.7.0 移除。

## 账号

<Link to="/knoxstudio/sign-in">用 KnoxStudio 登录</Link>。已连接为 @username。**退出登录** 会丢掉钥匙串，并在有网时 **撤销** 服务器上铸出的密钥。

提示文案仍可能提到 KnoxChat 密钥；按钮是 OAuth。没有粘贴密钥的字段。

## 视频生成

时长（自动或目录时长）、分辨率、宽高比、**包含音频**、**水印**、**末帧**。

Manager 被指示不要再问你这些；在这里改。存在 `~/.knoxmedia/defaults.yaml`。

## 音频生成

格式 **MP3 / WAV / Opus**。采样率 16000 / 24000 / 44100 / 48000 Hz。

## 执行

并行任务、工具轮次、超时、**推理强度** 关 / 低 / 中 / 高。

## 视频连续性

| 开关 | 作用 |
|---|---|
| **帧串联** | 末帧 → 下一镜首帧 |
| **顺序模式** | 一次一镜，对并行 |
| **视觉分析** | 分析已完成帧；关掉则启发式 |
| **环境同步** | 保持设定一致 |
| **运动连续性** | 把「从……继续」注入提示 |

页脚显示配置路径。<Link to="/knoxstudio/production/sequences">视频序列</Link>。
