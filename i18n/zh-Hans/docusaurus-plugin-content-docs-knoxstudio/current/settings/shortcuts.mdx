# 键盘快捷键

在应用里按 <kbd>?</kbd> 打开浮层。和 **帮助 → 键盘快捷键** / **显示 → 键盘快捷键** 同一份列表。KnoxStudio 只做 macOS。

焦点很重要：NLE 组合键作用在时间线/画布；剧本和 Explorer 有自己的组。

## 播放

| 键 | 动作 |
|---|---|
| 空格 | 播放 / 暂停 |
| J K L | 倒放 / 暂停 / 播放（连点 2× / 4× / 8×） |
| Home / End | 到开头 / 结尾 |
| ← → | 步进一帧（让给注释微移） |
| ⌘← ⌘→ | 上一 / 下一标记 |
| ⌥→ | 下一片段起点 |
| ⇧L | 循环 |

传输条 ±1 秒没有浮层快捷键。

## 剪辑

| 键 | 动作 |
|---|---|
| T / W / E | 在播放头分割 / 裁前 / 裁后 |
| B Y A V | 刀片 / 滑动 / 磁性 / 选择 |
| Z | 区域缩放 |
| I O | 入 / 出点 |
| M | 标记 |
| ⌘T | 添加转场 |
| ⌘⇧F | 定格 |
| ⌘] ⌘[ | 旋转 90° |
| ⌥ 拖 / ⌘ 拖 / ⌥ 放下 / ⇧ 拖 | 复制 / 覆盖 / 替换 / 约束 |
| ⌥ 拖 | 移动变换原点 |

## 选择

| 键 | 动作 |
|---|---|
| ⌘A | 全选片段 |
| ⌘C ⌘X | 复制 / 剪切（选中菱形时是关键帧） |
| ⌘V | 贴到播放头 |
| ⌘D | 复制一份 |
| Delete / Backspace | 删除 |
| ⇧Delete / ⇧Backspace | 波纹删除 |
| ⌘Delete / ⌘Backspace | 波纹删除入出点 |
| ⌘G / ⌘U | 编组 / 取消 |
| ⌘⌥G | 新建复合片段 |
| ⌘↑ | 父序列 |
| ⌘⌥L | 锁定 / 解锁 |

## 注释

1–9、0、⇧0 见 <Link to="/knoxstudio/canvas/annotations">注释</Link>。方向键微移（⇧ = 5 倍）。

## 时间线

| 键 | 动作 |
|---|---|
| Tab | 循环 正常 / 波纹 / 插入 / 覆盖 |
| N | 吸附 |
| ⌘⇧T / ⌘⌥T | 加视频 / 音频轨 |
| ⌘⌥↑ ↓ | 移动轨道 |
| ⌘⇧Backspace | 删除所选轨道 |
| ⇧G | 曲线编辑器 |
| ' | 安全区 |
| S | 独奏轨道 |
| ⇧Z / ⌥Z / = − | 适配 / 选区 / 缩放 |
| ⌘⇧G | 重新生成片段 |
| ? | 快捷键帮助 |

## 项目

⌘N 新建 · ⌘S 保存 · ⌘⇧S 另存为 · ⌘O 打开 · ⌘E 导出 · ⌘, 偏好设置 · Esc 清除选择 · ⌘Z / ⌘⇧Z 撤销/重做。

## 导航（NLE）

⌘1 检查器 · ⌘2 Agent · ⌘3 角色 · ⌘4 剧本。

## SI Agent

⌘K 聚焦对话 · ⌘F 搜索对话 · ⌘⇧A 多选消息 · ⌘G 从输入生成 · ⌘⇧V 语音 · ⌘Enter 发送 · ⇧Enter 换行 · 1–9 选 Agent 问题选项。

## Explorer（树聚焦）

⌘N 新建文件 · ⌘⇧N / ⌥⌘N 新建文件夹 · F2 / Enter 重命名 · 空格预览 · ⌘Enter 打开 · Backspace 废纸篓 · ⌘⇧Backspace 永久删除 · ⌘C ⌘X ⌘V ⌘D 复制/剪切/粘贴/复制一份 · ⌘⌥C 相对路径 · ⌘⌥⇧C 绝对路径 · ⌘Z / ⌘⇧Z 撤销/重做 · ⌘↑ 父级 · 折叠/展开 · ⌘⇧. 隐藏文件 · ⌥↑ ⌥↓ 上一/下一文件夹 · ⌥⌘R 揭示 · ⌘⌥T 终端。

## 剧本（编辑器聚焦）

⌘1 ⌘2 ⌘3 模式 · ⌘G 跳到场次 · ⌘F 查找 · F3 / ⇧F3 查找下一个 · ⌘↑ ⌘↓ 上一/下一场 · ⌘W 关闭标签 · ⌘B 缩略图 · ⌘L 行号 · ⌘⇧E 导出 HTML · 导出 FDX（菜单）· ⌘P 打印预览 · ⌘N 新建文件。

## 调试和窗口

⌘⇧D 调试控制台 · [ ] 日志详细程度（控制台打开时）· ⌘⌥F 帧率监视 · ⌘H 隐藏 · ⌘⌥H 隐藏其他 · ⌘Q 退出。
