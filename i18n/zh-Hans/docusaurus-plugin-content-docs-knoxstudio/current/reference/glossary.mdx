# 词汇表

| 词 | 含义 |
|---|---|
| **SI Agent** | 右侧栏工作室 Agent（通话时是 Voice Director） |
| **Manager** | 默认专家：生成和路由 |
| **Writer** | `~/.knoxmedia` 下的文档和剧本 |
| **Editor** | 用自然语言做时间线操作 |
| **Director** | 从提示或剧本出发的分镜流水线 |
| **Storyboard** | 风格 → 剧本 → 演员 → 帧 → 视频流水线 |
| **Voice Director** | 同一 Agent 的实时语音对语音 |
| **确认 / 自动** | 生成和破坏性编辑是否等批准 |
| **Explorer** | `~/.knoxmedia` 左侧树 |
| **画布** | 预览合成器（中央标签） |
| **剧本** | 写作表面（中央标签） |
| **`.knoxstudio`** | 项目包 |
| **`~/.knoxmedia`** | 生成的媒体、文档、角色、对话库、配置 |
| **Knox-Studio** | 模型 id `knox/knox-studio`——一个模型，服务器路由专家 |
| **复合片段** | 嵌套序列 |
| **波纹 / 插入 / 覆盖** | 时间线编辑模式（外加正常） |
| **角色** | 带参考和音色的具名演员记录 |
| **视频序列** | 带连贯性的多镜头任务 |
| **一条 / 变体** | 同一提示的交替 SI 生成 |
| **anydoc** | Office/PDF → Markdown 转换器 |
| **Knox 方言** | 剧本里的 `[NAME]` 角色提示 |
| **录制设置** | 开录前的预检对话框（权限、电平、**本次将包含**、开始录制） |
| **跟随** | 把一层贴到另一片段的位置上 |
| **自动关键帧** | 检查器复选框：每次更改都在播放头写关键帧 |
| **裁切** | 操作页 / 画布内侧手柄上的归一化源窗口 |
| **复合片段 / 嵌套** | `.knoxstudio` 包里的嵌套序列 |
| **图片生成** | 时间线工具栏：把所选静帧合成一张生成图 |
