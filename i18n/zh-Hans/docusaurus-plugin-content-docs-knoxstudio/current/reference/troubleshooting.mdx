# 故障排除

## 登录

- 别的应用占了 **8732** → 退出它，或对话框提示端口占用。
- 超时 / 拒绝 / 状态不匹配 → **取消**，再试 **用 KnoxStudio 登录**。
- 离线或 TLS 截断 → <Link to="/knoxstudio/safety/network">网络</Link>。
- 退出登录在有网时会撤销铸出的密钥。若离线退出，到 [knoxstudio.ai/keys](https://knoxstudio.ai/keys) 撤销 **KnoxStudio Desktop**。

## 采集

- 黑屏 / 没有显示器：给 KnoxStudio 打开 **屏幕录制**，**完全退出再打开**。
- 没有麦 / 摄像头：系统设置 → 隐私，然后 **偏好设置 → 设备 → 刷新设备**。
- 没有系统音频：macOS 13+，屏幕与系统音频录制。
- 设备页缺少 FFmpeg：直到捆绑二进制在，录制和导出都被拦住。

## 时间线 / 导出

- 传输条 **缺失媒体** 徽章打开重新链接对话框。每个文件：**重新链接**、**跳过**（对话框不关），或跳过剩余并关闭。重新链接某个文件时，也会匹配该文件夹里 **同名** 的其他缺失片段。在链接或跳过之前，导出不会跑。
- 导出后校验失败：ffprobe 时长或流不匹配——试软件编码器或换格式。
- 不能导出进项目包——换一个文件夹。
- 纯音频导出需要真正带音频的片段。

## Voice Director

- **语音错误** 时点麦克风重试。
- 回声：打开耳机；回声门控默认开。
- 通话进行中会跳过确认——需要批准卡片就挂断。

## 剧本

- 文学体 / Fountain 场次重排被压平已在 1.7.3 修复——若仍看到请更新。
- PDF 导出：用 HTML + 打印 → 存储为 PDF。

## 日志和恢复

**帮助 → 调试控制台**（<kbd>⌘⇧D</kbd>）、**错误日志**。若错误日志是空的，在辅助功能偏好打开 **在本机保存崩溃报告**。

启动对话框：

| 对话框 | 按钮 | 会发生什么 |
|---|---|---|
| **崩溃恢复** | 恢复 / 查看报告 / 忽略 | 「恢复」会重新打开上次的项目；如有自动保存快照则从快照恢复 |
| **未完成的录制** | 恢复 / 放弃 | 恢复把孤立片段放到时间线；放弃删除残留文件 |
| **自动保存选择器** | 快照列表 | 项目打不开时，从 `~/.knoxmedia/projects/autosave/` 最近 **5** 份里挑一份 |

<kbd>⌘⌥F</kbd> 切换 FPS 叠加（帮助）。
