# 1.7 新内容

面向用户的要点。完整工程变更见仓库 [CHANGELOG.md](https://github.com/knoxchat/knoxstudio/blob/main/CHANGELOG.md)。

## 1.7.3

- 强制 GitHub Release 更新（不能跳过版本）
- 剧本阅读 / 编辑 / 大纲，One Dark Pro Markdown，Fountain + Knox + 文学体方言
- 导出 HTML、Final Draft（FDX）、Knox Markdown；打印预览 ⌘P
- 角色、关系和评论面板

## 1.7.2

- 角色里的音色库和合集
- 变声使用账号已选音色
- 公开默认 TTS 音色 **Jarnathan**

## 1.7.1

- Explorer、检查器、时间线、画布、剧本作为 Voice Director HUD 伴随窗口
- HUD 跟随浅色和深色主题

## 1.7.0

- 圆形 **Voice Director** 圆球
- 左侧栏改名为 **Explorer**
- 定位为通用 SI 工作室（不只是视频）
- **用 KnoxStudio 登录** 是唯一连接路径
- 一个 `knox/knox-studio` 模型；服务器选专家

## 1.6.x（工作室仍这样工作）

- BM25 + ripgrep 资料库搜索；`@` 能解析不在时间线上的文件
- SI 配置是单页
- 录制倒计时 1–60 秒或关闭
