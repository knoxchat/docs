# 混音台

波形画在音频片段上。检查器 **音频** 就是混音台。

## 轨道条

每条可混音轨道：静音、独奏（时间线上 <kbd>S</kbd>）、音量 **0–200%**（在标题上滚动）、声像 **−100…+100**、实时峰值 / RMS 表。

## 每个片段

音量（可打关键帧）、声像（片段 + 轨道合成）、淡入 / 淡出、静音。需要独立画面和声音时，在视频片段上 **分离音频**。

## 处理

| 工具 | 说明 |
|---|---|
| **响度归一化** | 走 **导出** 路径 |
| **闪避** | 量、起音毫秒、释放毫秒（默认 0.65 / 50 / 250） |
| **降噪** | 导出路径 |
| **三段 EQ** + 高通 | **人声** 预设和重置 |
| **压缩** + 限制 | |

## 重叠混合

片段重叠时：**交叉淡化**、**等功率**（默认）、**全混合**、**硬切**。

## 纯音频导出

MP3（128 / 192 / 256 / 320 kbps）和 WAV（PCM 无损）。内置预设 **Audio MP3 320 kbps** 和 **Audio WAV**。项目里必须有带音频的片段。<Link to="/knoxstudio/export/formats">导出</Link>。
