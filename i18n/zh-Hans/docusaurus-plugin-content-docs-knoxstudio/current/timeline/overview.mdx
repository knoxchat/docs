# 时间线概览

KnoxStudio 是真正的非线性编辑器。底栏是传输条 + 时间线。需要的话可以弹成时间线 HUD 放到第二块屏。

## 轨道种类

| 种类 | 前缀 | 说明 |
|---|---|---|
| **视频** | V | 画面 |
| **音频** | A | 麦、系统音频、音乐、旁白 |
| **摄像头** | C | 一条里的画中画或全画面 |
| **注释** | N | 叠加形状和标题；没有媒体文件 |
| **调整** | G | 给下方视频调色；没有媒体 |
| **字幕** | CC | 字幕 cue；默认不允许重叠 |

每条轨道：可见（眼睛）、**锁定**、**静音**、**独奏**、音量（在标题上滚动）、声像、允许重叠、高度 36–160 px（默认 58）。双击重命名。拖 **轨道标题** 重排；拖标题边缘改高度。<kbd>⌘⇧T</kbd> 加视频轨，<kbd>⌘⌥T</kbd> 加音频轨，<kbd>⌘⌥↑</kbd> / <kbd>⌘⌥↓</kbd> 移动，<kbd>⌘⇧⌫</kbd> 删除所选轨道。<kbd>S</kbd> 独奏。

Shift / Option 会改变右键菜单里「添加轨道」的行为。空隙 / 右键菜单也可以添加 **注释 / 调整 / 字幕** 轨。

## 拖到新轨道

把片段拖到现有轨道 **上方、中间或下方**，直到插入条显示 **放到此处以创建新轨道**。片段会落到对应种类的新轨道。拖到列表边缘时会自动滚动。

<kbd>⌥</kbd>-拖可以复制到另一条轨道 **或** 新轨道。最后一段离开后，空轨道会被删掉。

## 缩放和适配

| 键 | 动作 |
|---|---|
| <kbd>=</kbd> / <kbd>-</kbd> | 放大 / 缩小 |
| <kbd>⇧Z</kbd> | 适配整段 |
| <kbd>⌥Z</kbd> | 适配选区 |
| <kbd>Z</kbd> | 区域缩放工具 |
| Ctrl+滚轮 | 缩放 |
| 滑杆 | 0.1–20 |

## 吸附

<kbd>N</kbd> 切换吸附。边缘吸附到其他片段、**标记** 和 **播放头**。阈值 0.1 秒。

## 播放

<kbd>Space</kbd> 播放 / 暂停。<kbd>J</kbd> <kbd>K</kbd> <kbd>L</kbd> 倒放 / 暂停 / 播放（连点 2× / 4× / 8×）。Home / End，方向键步进一帧（选中注释时方向键让给微移）。<kbd>⇧L</kbd> 循环。传输条 ±1 秒按钮没有浮层快捷键。

播放质量 **自动 / 代理 / 全质量** 在传输条上。导出始终用原始文件。

## 撤销

<kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd>。传输条工具提示显示历史步数和大约 MB；栈太大时会有内存警告。
