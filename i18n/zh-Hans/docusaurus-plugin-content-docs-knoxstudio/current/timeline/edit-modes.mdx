# 编辑模式与工具

<kbd>Tab</kbd> 循环编辑模式。时间线工具栏芯片显示当前模式。

## 编辑模式

| 模式 | 会发生什么 |
|---|---|
| **正常** | 自由重叠 / 交叉淡化。空隙一直留到你合上。 |
| **波纹** | 删除和移动会在该轨合上或打开空隙。 |
| **插入** | 放下片段时把后面的片段往右推。 |
| **覆盖** | 放下时会切开 / 裁掉下面的片段。 |

即使在其他模式，<kbd>⌘</kbd>-拖也是覆盖。<kbd>⌥</kbd>-拖复制（包括拖到 **新轨道**）。<kbd>⌥</kbd>-放下替换。<kbd>⇧</kbd>-拖约束时间和轨道。

## 工具

| 工具 | 键 | 行为 |
|---|---|---|
| **选择** | <kbd>V</kbd> | 移动、裁边缘、框选 |
| **刀片** | <kbd>B</kbd> | 点击分割 |
| **滑动** | <kbd>Y</kbd> | 拖片段中间改变素材偏移，边缘不动 |
| **磁性** | <kbd>A</kbd> | 移动后合上被拖轨道上的洞 |

<kbd>Z</kbd> 是区域缩放（不是第四种编辑模式）——在画布上拖矩形；进入 / 停留 / 退出在检查器 **操作** 页。

## 选择

单击、Shift 点范围、⌘ 点，或框选。空 **空隙** 也可以选——删掉或波纹合上。<kbd>⌘A</kbd> 全选片段。右键：选中该轨全部。

<kbd>Esc</kbd> 清除选择。
