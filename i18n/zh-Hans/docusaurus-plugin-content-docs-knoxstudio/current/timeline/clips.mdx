# 片段

片段在轨道上。检查器 **片段** 和 **操作（视频）** 编辑当前选择。多数操作也在片段右键菜单里。

## 裁切和分割

| 键 | 动作 |
|---|---|
| 拖边缘 | 裁切 |
| <kbd>T</kbd> | 在播放头分割 |
| <kbd>W</kbd> | 把前端裁到播放头 |
| <kbd>E</kbd> | 把后端裁到播放头 |
| <kbd>Delete</kbd> | 删除 |
| <kbd>⇧Delete</kbd> | 波纹删除 |
| <kbd>⌘Delete</kbd> | 波纹删除 **入出点之间** |

## 剪贴板

<kbd>⌘C</kbd> / <kbd>⌘X</kbd> / <kbd>⌘V</kbd>（贴到播放头）/ <kbd>⌘D</kbd> 复制。若选中了关键帧菱形，复制 / 剪切作用在那些关键帧上。

## 速度、倒放、定格

检查器 **操作**：速度 **0.1–8×**、倒放、定格。<kbd>⌘⇧F</kbd> 定格（默认 **2 秒**，检查器 0.5–30 秒）。慢动作质量：**复制 / 混合 / 光流**。运动模糊在导出时用 FFmpeg `tmix`。

## 分离、旋转、锁定、颜色

- 有音频的视频片段可 **分离音频**——画面和声音独立。
- <kbd>⌘]</kbd> / <kbd>⌘[</kbd> 旋转 90°。
- <kbd>⌘⌥L</kbd> 锁定 / 解锁。
- 片段颜色：绿、蓝、橙、紫、红。

## 编组和复合

<kbd>⌘G</kbd> / <kbd>⌘U</kbd> 编组 / 取消。<kbd>⌘⌥G</kbd> **复合片段**（嵌套）。<kbd>⌘↑</kbd> 离开嵌套。<Link to="/knoxstudio/timeline/nests">嵌套片段</Link>。

## 色块和图片生成

空隙 / 片段菜单 **添加纯色片段** 插入一块填充（黑 / 白或取色），没有媒体文件。时长跟项目静帧默认。

时间线工具栏 **图片生成** 把 **所选静帧** 合成一张生成图（需要 <Link to="/knoxstudio/sign-in">登录</Link>）。Voice Director 的 `set_timeline` 可以触发同一控件。

## 右键额外（多为 SI）

右键片段：移到播放头、合上空隙 / 合上所有空隙、插入媒体 / 色块 / 文字 / 字幕、抽取帧 / 首帧 / 末帧 / 关键帧、在访达中显示、重新链接、**重新生成**（<kbd>⌘⇧G</kbd>）、**变体**、延长、自动字幕、人声分离、变声、分轨、为片段配乐。

右键 **空隙** 可添加注释 / 调整 / 字幕轨、插入媒体或色块。

重新生成 / 变体 / 字幕 / 分离需要登录。

## 适配模式

包含（默认）、覆盖、拉伸、无——媒体如何填满画布画幅。
