# 嵌套片段

**复合片段** 是嵌套：在父序列上把若干片段当成一个来剪。

## 做嵌套和离开

1. 选中片段。<kbd>⌘⌥G</kbd> **新建复合片段**。
2. 右键 **打开嵌套**（或双击复合片段）进去剪。窗口标题会显示嵌套名。若嵌套缓存还在建，打开嵌套会带等待提示。
3. <kbd>⌘↑</kbd> **父序列** / 离开嵌套。时间线工具栏 **离开嵌套** 芯片作用相同。

可以像导父项目一样 **导出嵌套**（范围 = 嵌套序列）。普通 **编组**（<kbd>⌘G</kbd>）让片段留在父轨道上一起移动。复合则把它们放进嵌套序列。

## 磁盘上

嵌套在 `.knoxstudio` 包的 `nests/` 下。保存父项目时也会写嵌套序列。<Link to="/knoxstudio/settings/data">磁盘上的数据</Link>。

## 限制

把嵌套当成子序列，而不是指向另一个项目文件的实时链接。嵌套里的缺失媒体和父级一样重新链接。
