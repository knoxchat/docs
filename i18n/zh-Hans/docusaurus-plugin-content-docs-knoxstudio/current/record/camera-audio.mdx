# 摄像头与音频

每个采集源都是独立文件和轨道。静音、裁切或删除其中一个不影响其他。

## 麦克风

- 在 **录制设置** 里开 / 关。
- 设备或 **系统默认（自动检测）**。
- 需要 **麦克风** 权限。应用里写了用途说明；macOS 第一次用时询问。

录完后麦克风片段就是普通音频：音量、声像、淡化、EQ、闪避。<Link to="/knoxstudio/audio/mixer">混音台</Link>。

## 系统音频

- 开 / 关。界面注明 **macOS 13+**。
- 回路采集 Mac 正在播放的声音（浏览器、其他应用）。
- 权限在 **隐私与安全性 → 屏幕与系统音频录制**（和屏幕录制同一个屏幕采集面板）。

回路不可用时录制仍继续；会出现系统音频静音警告。

## 摄像头

- 开 / 关。设备或 **默认**。
- 录制设置里有圆形 **实时预览**。
- 落到 **摄像头** 轨道。检查器：画中画形状 **圆**（默认）、**圆角矩形**、**方形** 或 **全画面**。偏移已保存，画面和声音对齐。

## 实时指示

会话已武装或正在录时，传输条显示麦 / 系统音频 / 摄像头指示，让你看见会采什么。

## 录完之后

不需要拆轨——源已经分开。若之后导入封装好的文件，片段右键 **分离音频** 把画面和声音拆开。

登录后可对采集片段做人声分离、变声或分轨。<Link to="/knoxstudio/sign-in">登录</Link>。<Link to="/knoxstudio/audio/process">处理音频</Link>。
