# 光标与点击效果

KnoxStudio 把 **光标路径** 和 **点击事件** 跟这一条一起记下。预览和导出再合成这些叠加——在那之前不会烧进 `.mov`，所以事后还能改样式。

## 点击样式

**偏好设置 → 录制**（检查器里也可按片段覆盖）：

| 样式 | 在录制偏好下拉里 |
|---|---|
| **圆环** | 默认 |
| **实心** | 有 |
| **聚光** | 有 |
| **涟漪** | 有 |
| **声呐** | 有 |
| **冻结环** | 有 |

## 时间与颜色

| 控件 | 范围 / 说明 |
|---|---|
| 左键颜色 | 偏好 + 检查器 |
| 右键颜色 | 偏好 + 检查器 |
| 半径 | 8–180 px |
| 时长 | 0.1–2.5 秒 |
| 不透明度 | 检查器 |
| 点击时 **自动缩放** | 检查器 |
| **显示指针** 叠加 | 来自记录的路径 |
| 指针缩放 | 检查器 |
| 点击时缩放 | 检查器 |

**显示光标** 和 **高亮点击** 是录制设置总开关。要干净桌面就关掉点击；若稍后打开指针叠加，路径仍能驱动它。

## 所见即所得

画布把光标和点击叠加与视频、摄像头、注释、转场合在一起。导出走同一条合成路径。安全区叠加 **不会** 导出。
