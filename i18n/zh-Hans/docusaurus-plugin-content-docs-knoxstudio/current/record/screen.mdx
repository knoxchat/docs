# 屏幕录制

KnoxStudio 用原生 macOS 采集。倒计时和预览里看到的，就是时间线和导出里得到的。

## 录制设置（预检）

**文件 → 录制设置** 或传输条上的设置按钮会打开一页预检——不是偏好设置表格。引言：「确认来源和权限后，录制将进入倒计时；若已关闭倒计时则立即开始。」

1. **权限芯片**：屏幕录制，以及打开了麦克风 / 摄像头时对应的芯片。可在这里请求，或 **打开设置**。授予屏幕录制后经常需要 **完全退出再打开**。
2. **来源** — 屏幕、麦克风、系统音频、摄像头开关。屏幕有显示器 / 窗口选择。麦克风和系统音频有 **实时电平**。
3. **本次将包含** — 窗口或显示器名、麦克风、摄像头和帧率，避免还没开麦就开始录。
4. **开始录制** — 进入倒计时（若倒计时关掉则立刻开始）。**取消** 关闭对话框，不采集。

传输条 **录制** 在尚未确认设置时会打开同一份预检。开始会被拦住：捕获引擎仍在启动、**缺少 FFmpeg**、屏幕采集关闭、或未授予屏幕录制。

第一次屏幕录制是 **另外** 一个系统对话框（**稍后** / **打开设置** / **授予权限**），不是这份预检。

## 你可以配什么

| 控件 | 默认 | 说明 |
|---|---|---|
| 屏幕 | 开 | 选一台 **显示器**，或 **窗口** 对整屏 |
| 帧率 | 60 | 与项目相同的预设（24–120）或自定义 1–120 |
| 倒计时 | 开，3 秒 | 1–60 秒，或关掉让录制立刻开始。同样的值在 <Link to="/knoxstudio/settings/preferences">偏好设置 → 录制</Link> |
| 显示光标 | 开 | 作为路径存在片段上 |
| 高亮点击 | 开 | <Link to="/knoxstudio/record/cursor-clicks">光标与点击效果</Link> |

麦克风、系统音频和摄像头是独立源——见 <Link to="/knoxstudio/record/camera-audio">摄像头与音频</Link>。

## 开始和停止

1. 在预检里点 **开始录制**，或设置完成后按传输条 **录制**。倒计时是变暗的环：**准备**、剩余秒数、<kbd>Esc</kbd> 取消。
2. 在被采集的显示器或窗口里工作。
3. 从传输条停止。片段 **收尾**（转圈）后落到时间线。

**一条的布局**

| 源 | 轨道 |
|---|---|
| 屏幕 `.mov` | 视频 |
| 摄像头（可选） | 摄像头，带对口型偏移 |
| 麦克风 | 音频（独立文件） |
| 系统音频 | 音频（独立文件） |

光标路径和点击事件存在 **片段上**，预览 / 导出合成时才烧进去。之后还能改样式。

## 恢复

若录到一半退出，**未完成的录制** 对话框提供 **恢复**（放到时间线）或 **放弃**（删除残留文件）。系统音频不可用时会有静音警告。

启动还会做健康检查。崩溃恢复是未保存项目的另一套对话框。<Link to="/knoxstudio/reference/troubleshooting">故障排除</Link>。

## 设备

**偏好设置 → 设备** 显示屏幕 / 摄像头权限芯片、FFmpeg 捆绑 / 系统 / 缺失、显示器和窗口数量，以及 **刷新设备**。缺少 FFmpeg 会拦住录制和导出。
