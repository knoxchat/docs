# Voice Director

作曲栏上的麦克风会启动 KnoxChat 实时（线上是 `gpt-realtime-2.1`；产品经 Knox-Studio 路由）。面板标题变成 **Voice Director**。需要麦克风权限和 <Link to="/knoxstudio/sign-in">已登录</Link> 密钥。

## 状态

**正在连接…**、**就绪 — 开始说话**、**正在听…**、**正在思考…**、**正在说…**、**语音错误 — 点麦克风重试**、**已按住**、**因回声静音**。

## 控件

**打断**、**暂停麦克风** / **恢复麦克风**、**挂断**、**打开圆形 HUD** / **返回编辑器（继续通话）**、**选择麦克风和扬声器**。

偏好设置：**Voice Director：耳机**、**插话**。扬声器回声会被门控，避免 Agent 回答自己；插话仍会上传不相关的语音。

## 圆形 HUD

桌面上的无框圆球。作曲栏麦克风旁的圆形按钮会打开它，并可最小化编辑器。挂断恢复编辑器。**返回编辑器** 把通话留在面板内的 Voice Director。

伴随窗口彼此独立：**Explorer**、**检查器**、**时间线**、**画布**、**剧本**、**Voice Director 对话**。关掉对话 **不会** 挂断。HUD 的 Escape：预览 → 对话 → 挂断。

圆球上的井：角色、剧本、Director、暂停、Storyboard、Writer、Editor；耳机、对话、返回编辑器、挂断。圆球上有实时字幕芯片。

口头 `set_studio_mode` 的权限比文字 Manager **更大**。口头 `@` 是 `target_item`。生成 / 资料库 / 时间线工具始终在；切模式后才有专家工具。

通话进行中，语音生成 **会跳过确认**。

## 你可以怎么说

直接说要做的事。不必等着去点图标——Voice Director 应当自己调工具。

| 你说 | 实际跑什么 |
|---|---|
| 「打开 Director」/「拆成镜头」 | Director 模式，然后分析 |
| 「写剧本」/「打开剧本」 | Writer |
| 「编辑器」/「裁掉这段」/「大声一点」 | **任意** 模式下的片段编辑——具体剪辑不必切模式 |
| 「做分镜」 | Storyboard 流水线 |
| 「用 Pablo」/「角色」 | 角色 |
| 「回到对话」 | Manager |
| 「生成视频 / 图 / 音乐 / 旁白 / 音效」 | 生成工具；结果落到时间线 |
| 「播放 / 暂停 / 跳过 / 循环 / 录制」 | 传输条 |
| 「显示时间线 / Explorer / 检查器 / 画布」 | 伴随 HUD（可以同时开好几个） |
| 「关掉对话」 | 关掉聊天，**不** 挂断 |
| 「导出入出点」 | 直接编码，不只打开导出框 |
| 「给这段上字幕」 | 给对准的片段上字幕 / 转写 |
| 「裁掉右边」/「铺满画面」 | 片段变换 |
| 「开始录制」/「现在开了哪些源」 | 录制设置 + 状态 |

口头 `@` / 「这段」/ 「采访」会先附上目标。`~/.knoxmedia` 里 **不在** 时间线上的文件（`@313.md`）走资料库搜索，不会问你路径。

只有你要求时才会改主题和语言。打开一个伴随窗口不得关掉其他窗口。
