# Director Mode

坞 **Director**。把一段提示或完整剧本交给它，它来计划制作。

## 界面里的引导步骤

1. 「描述你的场景、故事，或粘贴剧本。」
2. 「按 **分析**——SI 导演规划场次、镜头、构图和时长。」
3. 「审阅并编辑分镜表，然后开始流水线——片段会生成、串起来，放到时间线。」

提示：用 `@` 附一张图或一段素材给开场镜头做种子。

## 工作流

1. 打一段提示，或 **分析打开的剧本** / 剧本 **发送到 Director Mode**。
2. **分析** → **分析完成**。状态：**正在分析...**
3. 编辑 **分镜表**：**添加镜头**、**删除镜头**、上移 / 下移、提示、时长。「空镜头在生成时会跳过。」
4. **开始流水线**。状态：**正在生成...** / **等待确认**。
5. 每镜：**重新生成**、**仍然接受**、**重试**、**跳过此镜**。对白镜头显示 **对白**。
6. **添加到时间线**。**流水线完成** / **流水线失败** / **需要重新生成**。**重置** 重来。**取消** / **正在取消…**

指标：**预计输出**、**时长**、**场次**、**镜头**、**片段**。

## 连贯性

流水线由末帧驱动：第 N 镜的末帧成为第 N+1 镜的首帧。在 <Link to="/knoxstudio/settings/agent-config">SI 配置</Link> → 视频连续性里调 **帧串联**、顺序模式、视觉分析、环境同步和运动连续性。

<Link to="/knoxstudio/sign-in">登录</Link> 后 Knox-Studio 提供视觉——你 **不必** 在 SI 配置里添加视觉模型（那个标签已经没了）。残留 UI 文案仍可能写「添加视觉模型」。若已登录的目录没有视觉能力，Director 无法保持镜头视觉连续。
