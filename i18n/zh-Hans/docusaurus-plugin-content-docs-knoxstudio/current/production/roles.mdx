# 角色

坞 **角色**。「管理角色，让生成保持一致。」YAML 清单在 `~/.knoxmedia/roles/`（界面会显示路径）。

NLE 聚焦时 <kbd>⌘3</kbd> 切换角色。

## 添加角色

作曲栏：**输入角色名以添加...** Enter / Cmd+Enter，或 **添加角色**。搜索：**搜索角色**。空：**还没有角色**。

每个角色：名 / 姓、描述、别名、标签、备注、性别、年龄、族裔、头发、**默认服装**、**特质**、**风格提示**、**负向提示**、**颜色**、**音色 ID**。

## 主角对配角

点击切换。**主角** 驱动首帧（图生视频）。**配角** 仅作参考。默认是配角。

**激活** / **停用**。激活的角色出现在 Manager 作曲栏上下文条（最多两个名字 + `+N`）。

## 参考

**+ 参考图**、**+ 参考视频**。点击 = **主头像**，右键 = 分类 / 移除。分类：脸、全身、服装、表情、姿势、环境、其他。每个角色最多发送 **3** 张图。警告：**没有参考图——视觉信号很弱。**

**上传到云** 通过 KnoxChat `upload_media` / `create_asset` 上传参考。通知：「正在上传 N 张参考图…」、「已上传 N 个资源，可用于生成。」未登录会失败。

## 音色

粘贴 `voice_id` 或 **浏览音色库**——**我的音色**、**曲库**、**合集**、**搜索**。需要 <Link to="/knoxstudio/sign-in">登录</Link>。残留 UI 文案仍可能写「添加 KnoxChat 密钥」；1.7 没有粘贴密钥字段。后备公开 id：Jarnathan、Rachel、Adam、Sarah、Antoni、Lily。

## 删除

**删除这个角色？** 剧本阅读模式芯片在名字缺失时可以创建一个角色。
