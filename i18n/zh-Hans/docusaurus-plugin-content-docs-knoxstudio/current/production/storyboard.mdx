# Storyboard

坞 **Storyboard**。和 Director 分开。完整制作：剧本、肖像、关键帧和时间线片段。

介绍：「打开一个项目，选视觉风格，然后在下面描述故事，生成完整制作——剧本、肖像、关键帧和时间线片段。」

## 步骤

**风格** → **剧本** → **演员** → **场次** → **帧** → **视频**

1. **打开或创建项目**——**项目名**、**最近项目**、**打开 / 创建**。离开提示：**保存更改？** / **不保存**。
2. **选风格**：电影、电视剧、动漫、Pixar、卡通、奇幻、Noir、赛博朋克、自定义。或跳过：剧本之后再预览风格。
3. 描述剧情；**生成** 或 **自动**（「自动生成所有帧，然后在视频前暂停审阅」）。
4. 检查点（除非自动）：**审阅剧本** → **审阅风格提示** → **继续 → 生成风格预览** → **使用此风格** → **审阅角色提示** → **继续 → 生成肖像** → **审阅场次提示** → **继续 → 生成场次图像** → 每镜 **审阅第 N 镜开场关键帧** → **审阅全部关键帧** → 可选 **审阅后自动生成全部视频** → **生成视频**。
5. **制作完成！**「已把 N 个镜头加到时间线。」

还有：**提示日志**、**进度日志**、**导出到 /tmp**（调试）。**暂停** / **跳过** / **重试失败**。
