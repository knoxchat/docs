# 视频序列

SI Agent 标题栏胶片图标 → **视频序列**。空：「生成多镜头场景时，视频序列会出现在这里。」

分区：**进行中的序列**、**最近序列**。

## 状态

序列：草稿、进行中、已完成、已暂停、部分完成、已取消。  
镜头：等待、阻塞、生成中、已完成、失败、已跳过。

## 动作

**创建手动序列**、**暂停生成**、**继续生成**、**删除序列**、**重试失败镜头**、**删除全部失败镜头**、**取消剩余镜头**、**复制序列**、**发送到时间线**、**导入到时间线**、**添加镜头** / **编辑镜头**。

卡片显示 **带连贯性**、**环境增强提示**、**入帧从上一镜串来**、**序列进度**、**出帧**、时长 / 分辨率 / 比例。

桌面提醒：偏好设置 **桌面提醒**——「序列、导出和生成完成时显示通知」。

## 连续性开关

**SI 配置 → 视频连续性**：

| 开关 | 含义 |
|---|---|
| **帧串联** | 末帧 → 下一镜首帧 |
| **顺序模式** | 一次一镜，对并行 |
| **视觉分析** | 分析已完成帧；关掉则回退启发式 |
| **环境同步** | 保持场景设定一致 |
| **运动连续性** | 例如「从：主角向左跑 继续」 |
