# KnoxChat星桥 — 您的AI应用神经连接器

> *星桥命名来源于唐·苏味道《正月十五夜》诗其中：“火树银花合，星桥铁锁开。”*

星桥是内置于 KnoxChat 的 AI 应用连接器。从单一页面即可将 KnoxChat 与机器上的每一个 AI 编程助手建立联结——统一管理各应用的提供商、技能、提示词、会话和 MCP 服务器，并一键将所有流量路由至 KnoxChat。

Claude Desktop 与 Claude Code 共享技能、提示词和会话历史；统一的 MCP 与技能面板可将条目分发至所有支持的应用，无论您当前在哪个标签页。

## 功能概览

### 一键 Knox 连接

每个应用面板都会显示实时连接状态——当前模型、路由模式，以及 Knox 是否正在作为提供商使用。连接对话框会为各应用生成正确的配置（Claude 使用 Anthropic 格式，Codex、OpenCode、OpenClaw 和 Hermes 使用 OpenAI 兼容的 `/v1`），让您的 KnoxChat 账户驱动全部应用，无需手动编辑配置文件。

### 提供商管理与热切换

从精选预设或自定义端点添加提供商，保存前测试端点延迟，并即时切换各应用的活跃提供商。需要格式转换或 URL 重写的切换会自动经由内置本地代理完成，并清晰说明原因。

### 本地路由与自动故障转移

本地代理可接管应用流量以实现：

- 格式转换（例如为不支持应用原生协议的提供商使用 OpenAI Chat Completions）。
- Claude Desktop 本地路由，支持按角色映射模型（Sonnet / Opus / Haiku 路由）。
- 基于优先级的故障转移队列（P1 → P2 → …），含熔断器、错误率阈值与自动恢复——提供商故障不会拖垮您的会话。

停止代理后，会从备份恢复各应用的原始配置。

### 技能、提示词、会话与 MCP

- **技能** — 从发现目录或 ZIP 安装，跨应用同步，备份与恢复，并管理技能仓库。
- **提示词** — 共享提示词库，按应用应用。
- **会话** — 浏览、搜索、恢复并批量管理 Claude Code、Codex、Gemini 和 OpenCode 的本地会话历史，包括在您选择的终端中直接打开会话。
- **MCP** — 统一面板添加、导入、校验 MCP 服务器，并分发至所有支持的应用。

### 安全与维护

- 环境变量冲突检测会在 shell 导出（如 `ANTHROPIC_BASE_URL`）可能静默覆盖应用配置时发出警告，并提供移除选项。
- 配置导入/导出，以及可选的 WebDAV 与 S3 同步，保持多台机器配置一致。
- 深度链接导入可分享提供商、技能、提示词和 MCP 服务器。
- 完整的中英文本地化，与 KnoxChat 的语言设置同步。

## 系统要求

星桥管理的是本机上的工具——本地配置文件、SQLite 数据库、会话文件夹和本地代理——因此需要 **KnoxChat 桌面端应用**。在浏览器中打开该页面时会显示下载提示；Web 版构建不会因此出错。

## 快速开始

1. 安装并打开 KnoxChat 桌面端。
2. 从侧边栏打开 **星桥**。
3. 选择一个应用（例如 Claude Code），点击 **Connect** 将其与 KnoxChat 建立联结。
4. 可选：在应用顶栏启用本地路由或故障转移，并在各标签页管理技能、提示词、会话和 MCP 服务器。
