# KnoxChat 更新：API 基础 URL

### 之前：
- OpenAI API 兼容基础 URL：`https://knox.chat/v1`
- 标准 API 基础 URL：`https://knox.chat`

### 之后/现在

- 标准 API 基础 URL：`https://api.knox.chat`
