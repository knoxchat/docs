# KnoxCode — 在您项目中工作的 AI 编程 Agent

KnoxCode 是一款在您项目中工作的 AI 编程 Agent。描述您的需求——修复 Bug、添加功能、探索陌生代码——KnoxCode 会读取文件、进行编辑、运行命令并汇报结果。您始终掌控全局：敏感操作前会征求确认，跨会话记住对话历史，并遵循您为项目设定的规则。

## Knox Memory System

KnoxCode 由 [**Knox Memory System**](https://docs.knox.chat/blog/kms-docs)（[knox/knox-ms](https://docs.knox.chat/knox-ms-unlimited-formula)）驱动，这是 Knox 专为长时间编码工作打造的模型。与单一静态 LLM 不同，Knox-MS 是一个编排层，将规划、任务路由和持久记忆相结合，使上下文能够远超普通上下文窗口的限制。

KnoxCode **仅使用 `knox/knox-ms`**——没有独立的第三方模型选择器。所有 Agent 轮次均通过 Knox API（`https://api.knox.chat/v1`）上的 Knox-MS 完成。

### 工作原理

Knox-MS 在 Knox 后端实现了 **Plan–Task–Memory** 架构：

1. **Plan（规划）** — 分析每个请求的复杂度。需要规划时，Knox-MS 将目标拆解为带依赖关系的任务，并选择执行策略。
2. **Task（任务）** — 按难度将任务路由至底层模型（简单、中等、困难）。简单工作使用更快的模型；较难推理使用更强大的模型。独立任务可并行执行。
3. **Memory（记忆）** — 对话历史、摘要、提取的知识和向量嵌入按用户和会话存储。构建下一轮上下文时，Knox-MS 检索最相关的材料，而非发送完整对话记录。

对于 **编程 Agent 请求**（存在工具时），Knox-MS 切换为 **工具调用透传**：将请求直接转发至能力足够的底层模型，同时仍附加会话记忆并通过 Knox-MS 计费。这样可保持 OpenAI 兼容的工具循环，用于文件编辑、Shell 命令和搜索。

每轮响应后，后端会异步运行 **后处理**：上下文过大时自动摘要、知识图谱提取和学习模式记录——均不会增加您当轮请求的延迟。

### 记忆层级

记忆按五级层级组织，灵感来自人类记忆：

| 层级 | 保留时间 | 作用 |
| --- | --- | --- |
| **即时（Immediate）** | ~30 秒 | 当前轮次与刚完成的工作 |
| **短期（Short-term）** | ~20 分钟 | 会话内近期对话 |
| **中期（Medium-term）** | ~1 小时 | 会话范围内的上下文与工作状态 |
| **长期（Long-term）** | ~24 小时 | 摘要与跨轮次回忆 |
| **永久（Permanent）** | 跨会话 | 知识库、偏好与项目事实 |

热层数据存放在 Redis 中以实现快速访问；较旧的块会分层存入 S3 并按需加载。**记忆巩固**在后台运行——强化重要记忆、淡化低价值记忆，并归档至长期存储。

检索结合 **语义向量搜索**、**词法搜索** 和 **知识图谱遍历**，使 Agent 获得相关上下文，而无需塞满提示词。

### KnoxCode 自动发送的内容

KnoxCode 在每次模型调用时将本地会话接入 Knox-MS：

- **`session_id`** — 将各轮次关联到 Knox-MS 记忆，便于稍后恢复
- **`project_id`** — 在可用时将记忆限定于当前打开的项目
- **`include_reasoning`** — 在模型支持时展示推理过程

您无需手动配置这些参数；KnoxCode 通过其 Provider 层自动传递。

## Agent 编程如何工作

KnoxCode 运行 **Agent 循环**：您发送消息，Agent 思考、对代码库使用工具并回复。若仍需继续，它会持续工作直至任务完成或需要您的输入。

每次对话是一个带完整历史的 **会话**。您可以在 Agent 工作时进行引导，稍后从断点继续，并让长会话自动压缩以保持上下文可管理。后端的 Knox-MS 记忆与本地会话历史互补，支持跨会话回忆。

## 内置 Agent

KnoxCode 内置多种专用 Agent，应对不同工作场景：

| Agent | 用途 |
| --- | --- |
| **Build** | 主编程伙伴——读取、编辑、运行命令并交付变更 |
| **Explore** | 快速、只读的代码库搜索，用于查找文件、符号或模式 |
| **General** | 处理复杂多步任务，可与主 Agent 并行运行子任务 |

**Build** Agent 为默认选项。您可在会话中切换 Agent——需要只探索不编辑时使用 Explore，或将专注的子任务委派给其他 Agent。

## Agent 能做什么

KnoxCode Agent 在您的机器上使用真实工具，而非仅聊天：

- **读取和编辑** 源文件，并提供可审查的 diff
- **搜索** 代码库——按文件名模式或文本
- **运行 Shell 命令** — 测试、构建、Git 等
- **浏览网页** 查阅文档或 API
- **向您提问** 当决策需要您拍板时
- **跟踪进度** 通过内置待办列表管理多步任务

危险或敏感操作——编辑文件、运行命令、读取密钥——均经过 **权限** 控制。KnoxCode 可对每类操作全局或按 Agent 设置为允许、询问或阻止。
