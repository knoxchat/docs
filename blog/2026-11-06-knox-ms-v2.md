# Knox-MS V2: a memory your assistant can actually use

Most assistants forget. You explain a project, make a decision, come back a week later, and start over. Bigger chat windows delay that. They do not solve it.

**Knox-MS V2** is the memory behind Knox Core. It keeps a lasting store of what you have said and decided, then brings only the useful pieces into each reply. The working space of a single answer is limited. The memory itself is not.

![Knox Memory System](/img/kms-v2.png)

## A desk and a filing cabinet

A reply has to fit on the model’s desk. Dump a whole year of conversation onto that desk and two things go wrong: the important note is buried, and the desk overflows. Saving everything is easy. Getting the *right* note back, months later, is the hard part.

Knox-MS V2 is built around that distinction:

- **The desk is bounded.** Every reply stays inside the space of the model that is actually answering.
- **The filing cabinet is not.** Conversations, facts, and habits can grow without a cap.
- **We check that the right notes still arrive.** Storing something is not the same as remembering it.

The claim is a memory that stays usable as the history grows.

## How it feels to use

You pick Knox-MS in Knox Chat and keep talking. Sessions continue. Projects can last weeks or months. You do not have to paste the same background in every time.

What that looks like in practice:

- Come back to a long project and pick up where you left off.
- Ask what you decided last month, or what was true in September, even if the facts have changed since.
- Search your own memory the way you would search a set of notes: by the words you used, by a name or an error message, or by how people, projects, and decisions connect.
- See which memories were used in an answer, and forget the ones that should not be there.

The assistant plans. A large request is broken into steps. Simple steps go to a faster model; harder ones go to a stronger one. Memory sits under that work, so later steps can use what earlier ones learned.

## Original notes stay

Knox-MS keeps the **original notes**. Short summaries exist, but they are a table of contents. They help the system walk toward the right original. They do not replace it. When a memory is placed in a reply, you get the words that were actually stored, not a paraphrase of a paraphrase.

Unused notes can move further back in the cabinet so the front stays uncluttered. Moving them back is not deleting them. They stay reachable.

## Four ways to find the right note

Each reply starts with your latest message. Knox-MS looks through *your* memory — not anyone else’s — in four complementary ways, then keeps only what is likely to help and still fits on the desk.

1. **By the words.** Ordinary search over the notes themselves.
2. **By an exact phrase.** Names, error messages, quotes.
3. **By connections.** People, projects, decisions, and how they relate. If two things keep showing up together, that link can surface a note that word search would miss.
4. **By the outline.** A map of the whole store, so a huge history can be walked from the general heading down to the original page.

Nothing is strengthened just because it was looked up. A memory becomes more trusted when it actually helped an answer. Looking is not learning.

What the web, a file, or a tool said is kept as quoted material. It does not override a fact you stated yourself.

## Forgetting is a choice, and it is complete

Knox-MS does not throw notes away because they got old. Time can make a memory less likely to be pulled forward. It does not erase it.

You forget on purpose:

- one note
- a whole conversation
- a project
- everything

Forget means gone. The note, the search hits, the links that existed only because of it, and any summary that mentioned it. What remains is a record that something was erased — not the content. You can check that it is really gone. This cannot be undone.

If a fact was later corrected, the previous version is closed, not shredded. You can still ask how things stood on a given date.

## A quiet tidy-up overnight

While you are not using it, Knox-MS does a sleep-style pass over your cabinet. Duplicates are merged. The outline is refreshed from the notes that are still there. Notes that have not been useful recede. Notes that keep helping stay close at hand.

That pass does not delete. Deleting is yours.

## Your memory is yours

Every lookup is limited to your account before anything is chosen. Another person’s conversation cannot appear in yours. Extra access on the team side is not a way into someone else’s cabinet.

If you delete a session, that session’s memories go with it, the same way a single forget does.

## Try it

In Knox Chat, choose **Knox-MS** and keep a session going on something that actually lasts — a project, a set of preferences, a decision you will need next week. Come back later and ask about it. Open Memory if you want to browse, search, or forget.
