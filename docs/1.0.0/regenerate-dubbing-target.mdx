Rebuild dubbed audio for a language. Billed on `charged_seconds` from the response at the project model rate.

## Request

### Path Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| project_id | String | Yes | Dubbing project ID. |
| language_id | String | Yes | Language target ID. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/dubbing/project/proj_123/language/lang_456/transcript/regenerate \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## Response

### Success Response (200)

JSON including `charged_seconds` and updated language `status`.

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
