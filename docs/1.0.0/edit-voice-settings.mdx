`stability` corresponds to Stability; `similarity_boost` to Clarity + Similarity. **Not billed**.

## Request

### Path Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| voice_id | String | Yes | Voice ID. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `application/json` |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| stability | Number | No | Voice stability. |
| similarity_boost | Number | No | How closely to match the original voice. |
| style | Number | No | Style exaggeration. |
| speed | Number | No | Speech speed. 1.0 is default. |
| use_speaker_boost | Boolean | No | Speaker boost. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/voice_id/settings/edit \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"stability":0.5,"similarity_boost":0.75,"speed":1.0}'
```

## Response

### Success Response (200)

`{ "status": "ok" }` on success.

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
