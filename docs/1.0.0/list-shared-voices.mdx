Public Voice Library listing. **Not billed**. Default `page_size` 30, max 100.

## Request

### Query Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| page_size | Integer | No | 1–100, default 30. |
| page | Integer | No | Page number. |
| category | String | No | `professional`, `famous`, `high_quality`. |
| sort | String | No | `created_date`, `usage_character_count_1y`, `trending`, `cloned_by_count`. |
| min_notice_period_days | Integer | No | Minimum notice period filter. |
| featured | Boolean | No | Featured only. |
| include_custom_rates | Boolean | No | Include custom rates. |
| include_live_moderated | Boolean | No | Include live-moderated voices. |
| reader_app_enabled | Boolean | No | Reader-app enabled voices. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET "https://api.knoxstudio.ai/v1/shared-voices?page_size=30&sort=trending" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## Response

### Success Response (200)

Paginated shared voices JSON (`public_owner_id`, `voice_id`, `name`).

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
