<MethodEndpoint
  method={"post"}
  path={"https://api.knoxstudio.ai/v1/voices/{voice_id}/edit"}
>
</MethodEndpoint>

Update a voice. `name` is required. **Not billed**.

## Request

### Path Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| voice_id | String | Yes | Voice ID. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `multipart/form-data` |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| name | String | Yes | Display name. |
| files | File | No | Optional replacement samples. |
| description | String | No | Forwarded description. |
| labels | String | No | JSON object or JSON string of labels. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/voices/voice_id/edit \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "name=Studio Narrator"
```

## Response

### Success Response (200)

Updated voice JSON.

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
