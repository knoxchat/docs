Add another dubbed language. Billed at **source duration × model rate**. `target_language` is a BCP-47 tag.

## Request

### Path Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| project_id | String | Yes | Parent dubbing project ID. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `application/json` |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| target_language | String | Yes | BCP-47 language tag. |
| voice_settings.cloning_strength | Integer | No | 0–10. |
| translations | Object | No | Optional per-segment translations. At most 20,000 entries. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/dubbing/project/proj_123/language \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"target_language":"ja","voice_settings":{"cloning_strength":5}}'
```

## Response

### Success Response (200)

JSON for the new language target (`language_id`, `status`).

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
