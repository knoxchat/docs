List finetunes you can access (yours, workspace-shared, and curated). This read is **not billed**.

## Request

### Query Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| cursor | String | No | Next-page cursor from the previous response. |
| page_size | Integer | No | Default `50`, max `150`. |
| visibility | String | No | `private`, `workspace`, or `public`. |
| created_by | String | No | `self`, `workspace`, or `elevenlabs`. |
| sort | String | No | `created_at` (default) or `name`. |
| sort_direction | String | No | `asc` or `desc` (default `desc`). |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET "https://api.knoxstudio.ai/v1/music/finetunes?page_size=50&sort=created_at&sort_direction=desc" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## Response

### Success Response (200)

`finetunes` array plus a `cursor` for the next page when more results exist.

### Finetune object

| id | string | Finetune ID. |
| name | string | Display name (5–200 characters). |
| tags | array of strings | Associated tags. |
| model_id | string | Base music model. |
| created_at | string | UTC timestamp. |
| visibility | string | `private`, `workspace`, or `public`. |
| created_by | string | `self`, `workspace`, or `elevenlabs`. |
| status | string | `pending`, `in_progress`, `completed`, `failed`, `blocked`. |
| training_progress | number | 0.0–1.0. |
| primary_genre | string | Primary genre. |
| failure_reason | string | `audio_processing_failed`, `copyright_violation`, or `training_failed`. |

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }

}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
