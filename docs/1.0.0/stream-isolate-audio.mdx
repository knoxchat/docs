Same multipart body as [Isolate audio](/1.0.0/isolate-audio), but the isolated audio is streamed. Billed at **`$0.17`/minute**.

## Request

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `multipart/form-data` |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| audio | File | Yes | Audio or video file to isolate speech from. |
| file_format | String | No | `pcm_s16le_16` or `other`. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/audio-isolation/stream \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "audio=@interview.wav" \
     -o vocals.mp3
```

## Response

### Success Response (200)

Streaming isolated audio bytes.

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
