List accents for a TTS `model_id`. If set, `model_id` must be a valid TTS model. **Not billed**.

## Request

### Query Parameters

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| model_id | String | No | TTS model such as `eleven_multilingual_v2` or `eleven_v3`. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET "https://api.knoxstudio.ai/v1/voices/accents?model_id=eleven_multilingual_v2" \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY"
```

## Response

### Success Response (200)

JSON list of accent identifiers.

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
