Patch metadata. Visibility can only be set to `private` or `workspace`. **Not billed**.

## Request

### Path Parameters

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| finetune_id | String | Yes | Finetune ID. |

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `application/json`. |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | -------- | ----------- |
| name | String | No | Updated name, 5–200 characters. |
| tags | List of Strings | No | Replacement tag set. |
| primary_genre | String | No | Updated genre. |
| visibility | String | No | `private` or `workspace`. |

## cURL Example

```shell
curl -X PATCH https://api.knoxstudio.ai/v1/music/finetunes/ftn_123 \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{
  "name": "Studio folk set v2",
  "visibility": "workspace"
}'
```

## Response

### Success Response (200)

Updated finetune object (same schema as [Get music finetune](/1.0.0/get-music-finetune)).

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
