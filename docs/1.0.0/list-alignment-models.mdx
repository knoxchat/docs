Returns Forced Alignment models. Use `id` as `model_id`. Default `forced_alignment`. See [Forced Alignment](/forced-alignment).

Authentication is optional (public catalog **60/min**, cached **5 minutes**; a token filters the list).

## Request

This endpoint does not require any request parameters.

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | No | Optional `Bearer <token>`. Omit for the public catalog. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET https://api.knoxstudio.ai/v1/forced-alignment/models
```

### Response Schema

| Name | Type | Description |
| ---- | ---- | ----------- |
| data[].id | string | Send as `model_id`. |
| data[].max_duration_seconds | integer | `36000` (10 hours). |
| data[].max_characters | integer | `675000`. |
| data[].pricing.per_hour | string | USD per audio hour (`0.27`). |

```json

  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"

```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
