Returns Sound Effects models. Use `id` as `model_id`. Default `eleven_text_to_sound_v2`. See [Sound Effects](/sound-effects).

Authentication is optional (public catalog **60/min**, cached **5 minutes**; a token filters the list).

## Request

This endpoint does not require any request parameters.

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | No | Optional `Bearer <token>`. Omit for the public catalog. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET https://api.knoxstudio.ai/v1/sound-generation/models
```

## Response

### Success Response (200)

```json
{
  "data": [
    {
      "id": "eleven_text_to_sound_v2",
      "canonical_slug": "eleven_text_to_sound_v2",
      "name": "ElevenLabs Sound Effects v2",
      "created": 1705881600,
      "description": "Royalty-free sound effects from a text prompt. 0.5–30 seconds per generation. Billed per generated audio minute.",
      "chinese_description": "根据文本提示生成免版税音效，单次 0.5–30 秒，按生成音频分钟计费。",
      "max_duration_seconds": 30,
      "pricing": { "per_minute": "0.17" },
      "architecture": {
        "modality": "audio",
        "input_modalities": ["text"],
        "output_modalities": ["audio"],
        "tokenizer": "elevenlabs"
      }
    }

```

### Response Schema

| Name | Type | Description |
| ---- | ---- | ----------- |
| data[].id | string | Send as `model_id`. |
| data[].max_duration_seconds | integer | `30`. |
| data[].pricing.per_minute | string | USD per generated minute (`0.17`). |

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |
| ------ | ---- |
| `400` | WebSocket path called without `Upgrade: websocket`. |
| `401` | Missing or invalid API key. |
| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
| `429` | Rate limit exceeded. |
| `500` | Internal server error. |
