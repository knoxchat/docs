Returns Voice Isolator models. Use `id` as `model_id`. Default `audio_isolation`. See [Voice Isolator](/voice-isolator).

Authentication is optional (public catalog **60/min**, cached **5 minutes**; a token filters the list).

## Request

This endpoint does not require any request parameters.

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | No | Optional `Bearer <token>`. Omit for the public catalog. `xi-api-key` is also accepted. |

## cURL Example

```shell
curl -X GET https://api.knoxstudio.ai/v1/audio-isolation/models
```

## Response

### Success Response (200)

```json
{
  "data": [
    {
      "id": "audio_isolation",
      "canonical_slug": "audio_isolation",
      "name": "ElevenLabs Voice Isolator",
      "created": 1699920000,
      "description": "Remove background noise and isolate speech from audio or video. Up to 1 hour per request. Billed per audio minute.",
      "chinese_description": "从音频或视频中去除背景噪声并分离人声，单次最长 1 小时，按音频分钟计费。",
      "max_duration_seconds": 3600,
      "pricing": { "per_minute": "0.17" },
      "architecture": {
        "modality": "audio",
        "input_modalities": ["audio", "video"],
        "output_modalities": ["audio"],
        "tokenizer": "elevenlabs"
      }
    }
  ]
}
```

### Response Schema

| Name | Type | Description |
| ---- | ---- | ----------- |
| data[].id | string | Send as `model_id`. Always `audio_isolation`. |
| data[].max_duration_seconds | integer | `3600` (1 hour). |
| data[].pricing.per_minute | string | USD per audio minute (`0.17`). |
