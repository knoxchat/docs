Isolate vocals/speech from mixed audio or video. Files up to **500MB**, duration **100ms–1 hour**. Billed at **`$0.17`/minute**. Guide: [Voice Isolator](/voice-isolator).

## Request

### Request Headers

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| Authorization | String | Yes | `Bearer <token>` Knox API key. `xi-api-key` is also accepted. |
| Content-Type | String | Yes | `multipart/form-data` |

### Request Body

| Name | Type | Required | Description |
| ---- | ---- | ---- | ---- |
| audio | File | Yes | Audio or video file to isolate speech from. |
| file_format | String | No | `pcm_s16le_16` or `other` (encoded files such as MP3/WAV). |
| preview_b64 | String | No | Optional preview payload; forwarded upstream. |

## cURL Example

```shell
curl -X POST https://api.knoxstudio.ai/v1/audio-isolation \
     -H "Authorization: Bearer $KNOXCHAT_API_KEY" \
     -F "audio=@interview.wav" \
     -F "file_format=other" \
     -o vocals.mp3
```

## Response

### Success Response (200)

The isolated audio file. `Content-Type` follows the upstream codec (typically MP3).

## Error Responses

Validation uses HTTP `422`:

```json
{
  "detail": [
    {
      "loc": ["body", "field"],
      "msg": "…",
      "type": "value_error"
    }
  ]
}
```

Other errors use `{ "detail": "message" }`.

| Status | When |

| `402` | Insufficient credits. |
| `403` | Token is not allowed to use this model. |
| `404` | Resource not found. |
| `422` | Validation error. |
